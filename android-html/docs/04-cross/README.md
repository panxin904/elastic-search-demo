## 🎯 选型决策

- **业务复杂 + UI 一致**：Flutter
- **前端团队**：React Native
- **共享业务逻辑**：Kotlin Multiplatform
- **保守方案**：原生 + 工具链整合

## 📚 学习路径

- **入门**：选定一种框架跑通 Demo
- **进阶**：状态管理 + 性能优化 + 原生互调
- **高级**：混合栈（Flutter + 原生 Activity）
