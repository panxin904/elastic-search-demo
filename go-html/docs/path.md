# 📖 Go 学习路径

> 根据你的角色选择对应路径，每条路径推荐了核心阅读顺序。

## 🌱 入门路径

适合**刚接触 Go**的初学者。

1. 阅读首页（[/](/)）了解整体结构
2. 查看 [🧭 思维导图](/mindmap) 熟悉全站布局
3. 选择一个子目录从 overview.md 开始
4. 边学边查 [📋 速查表](/cheatsheet)
5. 完成 cheatsheet.md 的练习题

## 🚀 进阶路径

适合**已有基础**的开发者。

- 深入各子目录的核心主题
- 阅读 cheatsheet.md 掌握高频命令
- 完成 questions.md 中的实战题
- 跨站对比：[🌐 知识图谱](/graph)

## 🏆 高级路径

适合**生产落地**的工程师。

- 性能调优 + 故障排查 + 监控告警
- 生态工具链 + 集成方案
- 贡献文档 / 改进站点
