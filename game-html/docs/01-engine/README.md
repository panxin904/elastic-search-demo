## 🎯 选型决策

- **移动休闲 / 中型**：Unity
- **PC / 主机 3A**：Unreal
- **独立 / 2D**：Godot
- **自研**：百万级代码 + 5+ 年 + 顶级图形团队

## 📚 学习路径

- **入门**：选定一个引擎跑通 Demo
