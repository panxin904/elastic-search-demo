# 🚶 游戏开发学习路径

> 三条路径覆盖"引擎使用者 / 图形程序员 / 联机 / AI 程序员"三种角色。按背景选择即可。

## 路径 1：引擎使用者（4 周）

适合：应用开发者转游戏 / 想做独立游戏 / 从零入门。

| Day | 主题 | 关键交付 |
|---|---|---|
| D1 | 引擎选型（Unity / Unreal / Godot 对比） | 选定主攻引擎 + 安装环境 |
| D2-3 | 场景搭建（地形 / 灯光 / 摄像机） | 第一个可漫游场景 |
| D4-5 | 物理系统（刚体 / 碰撞体 / Trigger） | 跑通平台跳跃 + 收集物 |
| D6-7 | 脚本系统（C# / Blueprint / GDScript） | 玩家控制 + 简单敌人 AI |
| W2 D1-2 | 动画系统（Animator / 状态机 / Blend Tree） | 角色跑跳攻击完整动画 |
| W2 D3 | UI 系统（UGUI / UMG / Control） | 主菜单 + HUD + 计分 |
| W2 D4-5 | 音频（Wwise / FMOD / 内置） | 脚步声 + 背景音乐 + 3D 衰减 |
| W2 D6-7 | 资产工作流（FBX / 纹理 / 材质） | 接入 DCC 美术资源 |
| W3 | 第一个完整 Demo（横版动作 / 解谜） | 5 分钟可玩关卡 |
| W4 | 性能初识（Profiler / Draw Call / GC） | 60 FPS 稳定 |

## 路径 2：图形程序员（6 周）

适合：计算机图形学背景 / 引擎底层开发者 / 想做渲染岗。

| 周 | 主题 | 关键交付 |
|---|---|---|
| W1 | 图形 API（DirectX 12 / Vulkan / Metal / WebGPU） | 第一个三角形 + 窗口化 |
| W2 | 渲染管线（前向 / 延迟 / Clustered） | 单 Pass 多光源场景 |
| W3 | PBR + IBL（Cook-Torrance / BRDF / 预滤波） | 真实感材质渲染 |
| W4 | 后处理链（Bloom / SSAO / TAA / Tonemap） | 电影级画面 |
| W5 | GPU 优化（Instancing / Batching / LOD） | 10 万物体 60 FPS |
| W6 | 进阶（Compute Shader / 光线追踪 / Mesh Shader） | 跑通 GPU 粒子或光追 Demo |

## 路径 3：联机 / AI 程序员（5 周）

适合：网络工程师 / AI 工程师 / 想做多人游戏 / 关卡 / 智能 NPC。

| 周 | 主题 | 关键交付 |
|---|---|---|
| W1 | 网络基础（TCP / UDP / KCP / WebSocket） | 自建回声服务器 |
| W2 | 同步模型（状态同步 / 帧同步 / 快照） | 房间制 Demo（2 客户端） |
| W3 | 一致性（预测 / 仲裁 / 回放） | 网络抖动 + 丢包测试通过 |
| W4 | 反外挂（服务器权威 / 协议加密 / 行为检测） | 反作弊 SDK 接入 |
| W5 | AI 决策（FSM / BT / GOAP）+ 寻路（NavMesh / Flow Field） | 智能敌人 + 动态障碍物 |

## 选路径决策树

- **想快速出作品** → 路径 1（4 周就有 Demo）
- **目标是引擎 / 渲染大厂 / 自研引擎** → 路径 2（数学 + 图形 API）
- **想做多人 / MOBA / FPS / 智能 NPC** → 路径 3（网络 + AI）
- **三者都做** → 路径 1 打底，再选 2 或 3 深入

## 推荐前置知识

- **数学**：线性代数（矩阵 / 向量 / 坐标系变换）+ 基础几何
- **编程**：C++ / C# / Rust 至少一门；了解指针 / 内存模型
- **英语**：引擎文档 / 论文以英文为主
- **客户端基础**：参考 `frontend` 站补客户端通识
