# 可访问性 (a11y)

## 🎯 为什么做 a11y

```
✅ 盲人、低视力、聋哑人、行动不便者都能使用
✅ SEO 提升（语义化 = 机器可读）
✅ 部分国家法律要求（ADA / EAA）
✅ 键盘操作 = 工程师 / 极客也喜欢
```

## 🛠 核心原则（POUR）

```
P - Perceivable（可感知）   — 信息必须能通过至少一种感官获取
O - Operable（可操作）      — UI 必须能操作（键盘、语音、开关）
U - Understandable（可理解） — 信息和操作必须清楚
R - Robust（健壮性）       — 辅助技术能可靠解析
```

## 🧱 语义化 HTML（最重要的第一步）

```html
<!-- ✅ 用对的标签 -->
<button type="button">提交</button>
<a href="/about">关于</a>
<label for="email">邮箱</label>
<input id="email" type="email" />

<!-- ❌ 错误做法 -->
<div onclick="submit()">提交</div>      <!-- 不能空格触发 -->
<div class="link" onclick="go()">跳转</div>  <!-- 不能右键打开 / 爬虫看不到 -->
<p>邮箱 <input /></p>                       <!-- 没有关联 label -->
```

## ⌨️ 键盘可访问

```html
<button>自然焦点</button>
<a href="/">自然焦点</a>
<div tabindex="0" role="button">自定义</div>  <!-- 凑合能用 -->
```

| 键 | 行为 |
|----|------|
| Tab | 下一个焦点 |
| Shift+Tab | 上一个 |
| Enter | 触发按钮 / 链接 |
| Space | 切换复选框 / 按钮激活 |
| Esc | 关闭弹窗 |
| Arrow | 单选按钮 / tab / 菜单导航 |

**焦点陷阱**：弹窗打开时把焦点限制在内部。

```ts
import { focusTrap } from 'focus-trap'

focusTrap(activate: true)
```

## 🎨 颜色对比度

```
WCAG AA：  正文 ≥ 4.5:1    大字 ≥ 3:1
WCAG AAA： 正文 ≥ 7:1    大字 ≥ 4.5:1
```

工具：
- Chrome DevTools 颜色对比检查
- axe-core 自动审计
- WebAIM Contrast Checker

## 🗣️ ARIA（不要乱用）

ARAI 补充 HTML 不能表达的语义。**优先使用原生标签**。

```html
<!-- 进度条 -->
<div role="progressbar" aria-valuenow="60" aria-valuemax="100" aria-valuemin="0">
  <div style="width: 60%"></div>
</div>

<!-- 实时通知 -->
<div role="status" aria-live="polite">已保存</div>

<!-- 模态对话框 -->
<div role="dialog" aria-modal="true" aria-labelledby="title" aria-describedby="desc">
  <h2 id="title">删除？</h2>
  <p id="desc">此操作不可撤销。</p>
</div>
```

## 🪟 弹窗 / Dialog

最佳实践：

```tsx
import { Dialog } from '@radix-ui/react-dialog'

<Dialog.Root>
  <Dialog.Trigger>打开</Dialog.Trigger>
  <Dialog.Portal>
    <Dialog.Overlay />
    <Dialog.Content
      aria-describedby="dialog-desc"
      onEscapeKeyDown={close}
      onPointerDownOutside={close}
    >
      <Dialog.Title>删除？</Dialog.Title>
      <Dialog.Description id="dialog-desc">不可撤销</Dialog.Description>
    </Dialog.Content>
  </Dialog.Portal>
</Dialog.Root>
```

- 自动焦点陷阱
- Esc 关闭
- 蒙层后焦点回到触发元素
- 屏幕阅读器宣告

Radix UI / Headless UI / Ant Design 已经实现好。

## 🖼 替代文本

```html
<!-- ✅ 描述作用 -->
<img src="logo.png" alt="Acme 公司" />

<!-- ✅ 装饰图：空 alt 跳过朗读 -->
<img src="bg-pattern.png" alt="" role="presentation" />

<!-- ❌ -->
<img src="logo.png" alt="图片" />
```

## 🎬 动画偏好

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

Vite / Next.js 类框架可以直接这样写。

## 🧰 自动审计工具

```bash
npm i -D @axe-core/cli
axe http://localhost:3000 --exit
```

集成到 CI 跑回归。

```ts
// Storybook addon-a11y
import '@storybook/addon-a11y'
```

Eslint 插件：`eslint-plugin-jsx-a11y` 会标出 a11y 错误。

## ✅ 检查清单

```
□ 所有 img 有 alt
□ 所有 form 有 label
□ 所有 button / link 可键盘触发
□ 焦点可见（:focus-visible 样式）
□ 弹窗焦点管理
□ 颜色对比度达标
□ 跳到主内容链接（Skip Link）
□ prefers-reduced-motion 兼容
□ H1 一页一次，有层级
□ 表单错误可被屏幕阅读器获取
```
