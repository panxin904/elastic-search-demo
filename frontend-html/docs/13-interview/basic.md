# 前端高频面试题

> 2024-2026 春招 / 秋招常考题汇总。

## 🔥 JavaScript 必会

1. **闭包**：原理 + 实战场景（防抖、Hooks、单次权限）
2. **原型链**：实现继承的几条路
3. **Event Loop**：浏览器 / Node 差别
4. **this 绑定**：call / apply / bind / new / 箭头函数
5. **Promise 全家桶**：all / allSettled / race / any
6. **深拷贝**：考虑循环引用 + Date / RegExp
7. **节流 / 防抖**
8. **柯里化 / 组合**

## ⚛️ React 必会

1. **Hooks 原理**：Fiber + 链表
2. **useEffect vs useLayoutEffect**
3. **状态管理选型**：useState / Context / Redux / Zustand
4. **RSC 与 Client Component 边界**
5. **Suspense + lazy 懒加载**
6. **性能优化**：memo / useMemo / useCallback / StartTransition
7. **受控 vs 非受控组件**
8. **错误边界 ErrorBoundary**

## 📜 TypeScript 必会

1. **泛型 + extends keyof**
2. **条件类型**：infer / Distributive
3. **工具类型**：`Partial / Omit / Record / ReturnType`
4. **类型守卫**：`is` / `as` / `satisfies`
5. **协变 / 逆变**

## 🛠️ 工程化

1. **Vite vs Webpack**：原理 + 速度
2. **Monorepo 收益 + 工具**
3. **CI/CD**：lint + test + build + deploy
4. **微前端**：Module Federation 原理

## 🎨 CSS

1. **盒模型** content-box vs border-box
2. **BFC 原理**
3. **垂直居中**：5 种方式
4. **动画**：transform vs top 性能
5. **Tailwind / CSS-in-JS 取舍**

## 🟢 Node.js

1. **事件循环阶段**
2. **Express / Fastify / Hono 区别**
3. **Stream 与 Buffer**
4. **Cluster / Worker Threads**

## 📡 网络

1. **HTTP/1.1 vs HTTP/2 vs HTTP/3**
2. **HTTPS 握手**
3. **WebSocket 与 SSE**
4. **跨域与 CORS**
5. **CDN 与缓存策略**

## ⚡ 性能

1. **CWV 三指标 + 优化**
2. **SSR / SSG / ISR**
3. **首屏优化 5 步**：CDN / 懒加载 / 预加载 / SSR / 减小 bundle

## 🛡️ 安全

1. **XSS** 攻击向量 + CSP
2. **CSRF**：SameSite Cookie / Token
3. **点击劫持**：X-Frame-Options

## 🧰 系统设计

1. **短链系统**
2. **评论系统**
3. **实时协作**
4. **CDN / 缓存策略**
5. **OAuth 2.0 流程**

## 🎯 回答套路

```
1. 一句话定义问题
2. 关键概念 / 术语（边说边画）
3. 核心原理（画图 / 例子）
4. 实战应用 / 注意事项
5. 边界 / 反例
```
