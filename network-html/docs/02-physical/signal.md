# 🔌 信号与编码

> 物理层将**比特流**转换成**物理信号**传输。

## 🎯 信号分类

### 模拟信号 vs 数字信号

```
模拟信号：连续变化（正弦波）
   ┌─╮   ╭─╮
   │ ╰─╮╭─╯ ╰─╮
───╯   ╰╯     ╰─── 时间
     
数字信号：离散（高低电平）
   ┌───┐ ┌─┐ ┌─────┐
   │   │ │ │ │     │
───┘   └─┘ └─┘     └── 时间
  1 1 0 1 0 1
```

| 类型 | 特点 | 应用 |
|---|---|---|
| 模拟信号 | 连续、随时间平滑变化 | 老式电话、广播 |
| 数字信号 | 离散、抗干扰强 | 现代网络 |

## 📊 编码方式

### 1. 不归零编码（NRZ）

```
1 → 高电平
0 → 低电平
问题：长串 0 或 1 时无法同步
```

### 2. 曼彻斯特编码（Manchester）

```
1 → 高→低跳变
0 → 低→高跳变（IEEE 802.3）
或反之（IEEE 802.4）

  1: ┌─┐     0: ┌─┐
     │ └─┐       │ ┌─┐
  ───┘   └──  ──┘ │ │ └──
                ┌─┘ └─┐
```

**优点：** 自带时钟同步

### 3. 差分曼彻斯特

```
每个码元中间都有跳变
0 → 码元开始时跳变
1 → 码元开始时不跳变
```

## 🔄 调制技术

### 基带传输 vs 频带传输

| 方式 | 含义 | 适用 |
|---|---|---|
| 基带 | 直接传输数字信号 | 局域网（以太网）|
| 频带 | 调制到高频载波 | 广域网、电话线 |

### 数字调制方式

| 调制 | 英文 | 改变 |
|---|---|---|
| 幅度键控 | ASK | 幅度 |
| 频移键控 | FSK | 频率 |
| 相移键控 | PSK | 相位 |
| 正交幅度 | QAM | 幅度 + 相位 |

## ⚡ 奈奎斯特定理

```
无噪声信道最大传输速率 = 2 × W × log₂(V)

W = 带宽（Hz）
V = 信号电平数（离散等级）

例：带宽 3 kHz，2 电平 → 6 kbps
```

## 📐 香农定理

```
有噪声信道最大传输速率 = W × log₂(1 + S/N)

W = 带宽
S/N = 信噪比

例：带宽 3 kHz，信噪比 30 dB (1000:1)
   = 3000 × log₂(1001) ≈ 30 kbps
```

**核心结论：**
- 带宽越大 → 速率越高
- 信噪比越大 → 速率越高
- 存在**理论上限**，无法突破

## 🎯 比特率 vs 波特率

```
比特率 = 波特率 × log₂(电平数)

例：波特率 1200，电平数 4 → 比特率 2400 bps
```

## 🛠️ 实际应用

**以太网编码：**
- 10 Mbps：曼彻斯特编码
- 100 Mbps：4B/5B 编码
- 1 Gbps：8B/10B 编码（脉冲幅度调制 PAM-5）
- 10 Gbps：64B/66B 编码

**光纤编码：**
- NRZ（非归零）
- PAM-4（4 级脉冲幅度调制）

## 🎓 面试高频问题

| 问题 | 关键点 |
|---|---|
| 曼彻斯特编码特点？| 自带时钟，每位中间跳变 |
| 奈奎斯特定理？| 2W log₂V，无噪声信道上限 |
| 香农定理？| W log₂(1+S/N)，有噪声信道上限 |
| NRZ 缺点？| 长串 0/1 失同步 |
