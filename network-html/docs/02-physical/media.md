# 🔌 传输介质

> 物理层用于传输信号的**媒介**，决定网络的带宽、距离和抗干扰性。

## 🎯 分类

```
传输介质
├── 有线介质
│   ├── 双绞线（Twisted Pair）
│   ├── 同轴电缆（Coaxial）
│   └── 光纤（Fiber Optic）
└── 无线介质
    ├── 无线电波
    ├── 微波
    └── 卫星
```

## 📊 有线介质对比

| 介质 | 类型 | 带宽 | 距离 | 抗干扰 | 成本 |
|---|---|---|---|---|---|
| **Cat5e** | 双绞线 | 100 MHz / 1 Gbps | 100m | 中 | 低 |
| **Cat6** | 双绞线 | 250 MHz / 10 Gbps | 55m | 中 | 低 |
| **Cat6a** | 双绞线 | 500 MHz / 10 Gbps | 100m | 高 | 中 |
| **Cat7** | 双绞线 | 600 MHz / 10 Gbps | 100m | 高 | 中 |
| **Cat8** | 双绞线 | 2000 MHz / 25-40 Gbps | 30m | 高 | 高 |
| **同轴电缆** | 同轴 | 1 GHz | 500m | 高 | 中 |
| **多模光纤** | 光纤 | 1-10 Gbps | 550m | 极高 | 高 |
| **单模光纤** | 光纤 | 100+ Gbps | 100km | 极高 | 极高 |

## 🔌 双绞线（Twisted Pair）

### 结构

```
外皮 ─┐
      │ 8 根铜线，两两双绞
      │ ┌─────┐
      └─│     │─── RJ45 水晶头
        │     │
        └─────┘
```

### 线序标准

**T568B（常用）：**
```
1. 白橙   2. 橙
3. 白绿   4. 蓝
5. 白蓝   6. 绿
7. 白棕   8. 棕
```

**T568A：** 1-2 与 3-6 对调

### 网线类型

| 类型 | 描述 | 用法 |
|---|---|---|
| **直连网线** | 两端相同（A-A 或 B-B）| 不同设备互联（PC-交换机）|
| **交叉网线** | 两端不同（A-B）| 同类设备互联（PC-PC，已淘汰）|

> 现代网卡自动翻转（Auto-MDIX），无需区分。

### 屏蔽类型

| 类型 | 说明 |
|---|---|
| **UTP** | 非屏蔽双绞线（最常用）|
| **STP** | 屏蔽双绞线（抗干扰）|
| **FTP** | 铝箔屏蔽双绞线 |
| **S/FTP** | 双重屏蔽 |

## 📡 同轴电缆（Coaxial）

```
结构（从内到外）：
  铜芯 → 绝缘层 → 屏蔽层 → 外皮
```

**类型：**
- **粗缆（10Base-5）：** 已淘汰
- **细缆（10Base-2）：** 已淘汰
- **宽带同轴电缆：** 有线电视、广电网络

## 💡 光纤（Fiber Optic）

### 结构

```
  ┌─────────────┐
  │ 包层 (Cladding) │ ← 折射率低
  ├─────────────┤
  │ 纤芯 (Core)    │ ← 折射率高，光传导
  ├─────────────┤
  │ 涂覆层 (Coating) │
  └─────────────┘
```

### 类型对比

| 类型 | 纤芯直径 | 光源 | 距离 | 带宽 | 成本 |
|---|---|---|---|---|---|
| **多模** | 50/62.5 μm | LED | 550m | 1-10 Gbps | 低 |
| **单模** | 9 μm | 激光 | 100km+ | 100+ Gbps | 高 |

### 光纤接口

- **SC**（大方头，方形卡扣）
- **LC**（小方头，模块化）
- **FC**（圆形螺纹）
- **ST**（圆形卡口）

### 光纤优点

- **超高带宽**：可达 Tbps 级
- **超长距离**：单模 100km+
- **抗电磁干扰**：完全不受电磁影响
- **低损耗**：长距离传输信号衰减小
- **安全**：难以窃听

## 📡 无线介质

| 类型 | 频率 | 距离 | 应用 |
|---|---|---|---|
| **无线电波** | 3 kHz - 300 GHz | 远 | 广播、WiFi |
| **微波** | 1-300 GHz | 直线 | 卫星、地面微波 |
| **红外** | 300 GHz - 400 THz | 短 | 遥控、近场通信 |
| **激光** | 高频 | 短 | 楼宇间点对点 |

### WiFi 频段

| 频段 | 频率 | 特点 |
|---|---|---|
| 2.4 GHz | 2.4-2.485 GHz | 穿墙强、干扰多 |
| 5 GHz | 5.15-5.85 GHz | 速度快、距离短 |
| 6 GHz | 5.925-7.125 GHz | WiFi 6E 最新 |

## 🎯 选型建议

| 场景 | 推荐介质 |
|---|---|
| 家庭 / 办公（100m 内）| Cat6 双绞线 |
| 数据中心机房（短距）| Cat6a / Cat8 |
| 数据中心互联（中距）| 多模光纤 / AOC |
| 城域网（10-80km）| 单模光纤 |
| 跨国 / 海底 | 单模光纤 + 波分复用 |
| 移动设备 | WiFi / 5G |
| 物联网终端 | LoRa / NB-IoT |

## 🛠️ 实际命令

```bash
# 查看网线连接状态
ethtool eth0
# Speed: 1000Mb/s   Duplex: Full   Link detected: yes

# 查看光纤模块信息
sudo ethtool -m eth0

# 测试网线连通性（推荐使用电缆测试仪）
```
