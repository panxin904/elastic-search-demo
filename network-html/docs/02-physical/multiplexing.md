# 📊 复用技术

> 在一条物理链路上传输**多路信号**，提升信道利用率。

## 🎯 三大复用方式

```
                一条物理链路
                     │
   ┌──────────┬──────┼──────┬──────────┐
   ↓          ↓      ↓      ↓          ↓
  信号1    信号2   信号3   信号4     信号5
```

| 复用方式 | 英文 | 区分依据 | 典型应用 |
|---|---|---|---|
| **频分复用** | FDM | 频率 | 无线电、有线电视 |
| **时分复用** | TDM | 时间 | 数字电话、E1/T1 |
| **波分复用** | WDM | 波长 | 光纤通信 |

## 📡 频分复用（FDM）

### 原理

将信道带宽划分为多个**不同频段**，每路信号占用一个频段。

```
频率 →
┌──────────────────────────────────────┐
│ ▓▓▓▓ │ ░░░░ │ ████ │ ▒▒▒▒ │          │ 信道总带宽
│ 频段1 │ 频段2 │ 频段3 │ 频段4 │ 保护带 │
│ 信号A │ 信号B │ 信号C │ 信号D │ 隔离   │
└──────────────────────────────────────┘
```

**应用：**
- 广播电台（每个电台一个频段）
- 有线电视（CATV）
- ADSL（上下行不同频段）

### ADSL

```
频率划分（典型）：
  0-4 kHz: 语音（电话）
  25-160 kHz: 上行（1 Mbps）
  240 kHz-1.5 MHz: 下行（8 Mbps）
```

## ⏱ 时分复用（TDM）

### 同步时分复用（STDM）

将时间划分为等长的**帧**，每帧包含若干**时隙**，每个时隙分配给一路信号。

```
一帧（Frame）：
┌─────┬─────┬─────┬─────┬─────┐
│ TS1 │ TS2 │ TS3 │ TS4 │ TS5 │ 时隙
├─────┼─────┼─────┼─────┼─────┤
│用户A│用户B│用户C│用户D│用户E│
└─────┴─────┴─────┴─────┴─────┘
时间 →
```

### 统计时分复用（STDM）

**按需分配**时隙，有数据的用户才分配，没有则跳过。

```
STDM：动态分配（更高效）
┌─────┬─────┬─────┬─────┬─────┐
│ A:1 │ B:1 │ A:2 │ C:1 │ A:3 │
└─────┴─────┴─────┴─────┴─────┘
用户A获得 3 个时隙，B/C 各 1 个
```

### E1 / T1 标准

| 标准 | 速率 | 时隙数 | 应用 |
|---|---|---|---|
| **T1** | 1.544 Mbps | 24 | 北美 |
| **E1** | 2.048 Mbps | 32（30 业务）| 欧洲、中国 |

## 💡 波分复用（WDM）

### 原理

在一根光纤上同时传输**多个不同波长**的光信号。

```
单根光纤：
  λ1 (1310 nm) ─→ 信号1
  λ2 (1550 nm) ─→ 信号2  ────→ 解复用 → 接收
  λ3 (1551 nm) ─→ 信号3
```

### 类型

| 类型 | 英文 | 波长间隔 | 容量 |
|---|---|---|---|
| **CWDM** | 粗波分复用 | 20 nm | 18 通道 |
| **DWDM** | 密集波分复用 | 0.4-1.6 nm | 160+ 通道 |

**DWDM 应用：** 单根光纤可达 **Tbps** 级容量。

## 📊 码分复用（CDM）

### 原理

每个用户分配**唯一码片序列**（Code），所有用户共享同一频段同时传输。

```
用户 A：码片 [+1, -1, +1, -1]
用户 B：码片 [+1, +1, -1, -1]
用户 C：码片 [+1, -1, -1, +1]

所有用户同时发送，接收端用对应码片做相关运算区分
```

### 应用：CDMA

- **3G 移动通信**
- **卫星通信**
- **GPS**（每个卫星有唯一码）

## 🔄 现代复用技术

### OFDM（正交频分复用）

将信道划分为多个**正交子载波**，每个子载波用子频段传输。

**应用：**
- WiFi（802.11a/g/n/ac/ax）
- 4G LTE
- 5G NR
- DVB 数字电视

### MIMO（多输入多输出）

**多天线同时收发**，复用空间维度。

```
        天线1 天线2 天线3 天线4
发送方   ●    ●    ●    ●
        ×    ×    ×    ×     ← 多路信号同时
接收方   ●    ●    ●    ●
```

**应用：**
- WiFi 802.11n/ac/ax（最多 8×8）
- 4G/5G 基站

### MU-MIMO

**多用户 MIMO**：AP 同时与多个设备通信。

## 🎯 选型对比

| 场景 | 复用技术 |
|---|---|
| 传统电话交换 | TDM（E1）|
| 模拟电视 | FDM |
| 光纤骨干网 | WDM / DWDM |
| WiFi | OFDM + MIMO |
| 4G/5G | OFDM + MIMO |
| 卫星通信 | CDMA |
