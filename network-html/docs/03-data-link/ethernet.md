# 🔗 以太网与交换机

> 以太网（Ethernet）是局域网**最主流**的技术，交换机是其核心设备。

## 🎯 以太网发展史

| 标准 | 年份 | 速率 | 介质 |
|---|---|---|---|
| 10Base-5 | 1980 | 10 Mbps | 粗同轴 |
| 10Base-2 | 1985 | 10 Mbps | 细同轴 |
| 10Base-T | 1990 | 10 Mbps | 双绞线 |
| 100Base-TX | 1995 | 100 Mbps | Cat5 |
| 1000Base-T | 1999 | 1 Gbps | Cat5e+ |
| 10GBase-T | 2006 | 10 Gbps | Cat6a+ |
| 40GBase-T | 2010 | 40 Gbps | Cat8 |
| 100GBase-T | 2016 | 100 Gbps | 光纤 |

## 🔌 以太网帧格式

```
┌─────────┬─────────┬────────┬──────────────┬──────┐
│ Dest MAC│ Src MAC │ EtherType│   Payload    │ FCS  │
│ 6 字节  │ 6 字节  │ 2 字节 │ 46-1500 字节 │4 字节│
└─────────┴─────────┴────────┴──────────────┴──────┘

最小帧：64 字节
最大帧：1518 字节（标准）/ 1522（VLAN Tag）
巨型帧：9 KB+
```

### 字段说明

| 字段 | 长度 | 含义 |
|---|---|---|
| 前导码 | 7 字节 | 0xAA × 7（同步）|
| SFD | 1 字节 | 帧开始定界符 0xAB |
| Dest MAC | 6 字节 | 目标 MAC 地址 |
| Src MAC | 6 字节 | 源 MAC 地址 |
| EtherType | 2 字节 | 上层协议（0x0800=IP, 0x0806=ARP）|
| Payload | 46-1500 字节 | 上层数据 |
| FCS | 4 字节 | CRC 校验 |

## 🔄 CSMA/CD 协议

**载波监听多路访问 / 碰撞检测**（已废弃，半双工时使用）

```
发送方：
  1. 监听信道（载波监听）
  2. 信道空闲 → 发送
  3. 信道忙 → 等待随机时间
  4. 发送中检测到碰撞 → 立即停止
  5. 发送 jamming 信号（32 bit）
  6. 等待随机时间后重试（指数退避）
```

**全双工交换式以太网**无需 CSMA/CD，因为不会碰撞。

## 🏢 交换机工作原理

### MAC 地址学习

```
1. 收到帧 → 记录源 MAC + 端口到 MAC 表
2. 查目标 MAC：
   - 在 MAC 表 → 转发到对应端口（单播）
   - 不在 MAC 表 → 泛洪（除接收端口外）
3. 收到响应 → 学习新 MAC
```

**MAC 表（CAM 表）示例：**
```
MAC 地址         端口   VLAN
00:1A:2B:...     Gi0/1  10
00:2C:3D:...     Gi0/2  10
00:3E:4F:...     Gi0/3  20
```

### 三种转发方式

| 方式 | 特点 |
|---|---|
| **存储转发**（Store-and-Forward）| 完整接收后校验，再转发（最常用）|
| **直通转发**（Cut-Through）| 读到目标 MAC 就转发，低延迟但可能传错帧 |
| **无碎片转发**（Fragment-Free）| 读到 64 字节再转发，过滤冲突碎片 |

## 🔄 交换机 vs 集线器 vs 路由器

| 设备 | 工作层 | 功能 |
|---|---|---|
| **集线器 (Hub)** | 物理层 | 广播所有端口 |
| **交换机 (Switch)** | 数据链路层 | 基于 MAC 智能转发 |
| **路由器 (Router)** | 网络层 | 基于 IP 跨网段转发 |
| **三层交换机** | 网络层 | 交换机 + 路由功能 |

## 🏢 交换机分类

### 按网络层次

| 类型 | 用途 | 性能 |
|---|---|---|
| **接入交换机** | 终端接入 | 24-48 端口，千兆 |
| **汇聚交换机** | 接入层汇聚 | 24 端口，万兆上行 |
| **核心交换机** | 高速转发 | 万兆 / 100G |
| **数据中心交换机** | 云计算 | 高密度 25G/100G |

### 按管理方式

| 类型 | 说明 |
|---|---|
| **傻瓜交换机** | 即插即用，无配置 |
| **网管交换机** | 支持 VLAN、ACL、SNMP |
| **三层交换机** | 支持路由功能 |

## 🛠️ 实战配置（华为/Cisco）

```bash
# 创建 VLAN
vlan 10
description "Engineering"

# 配置端口
interface GigabitEthernet0/0/1
port link-type access
port default vlan 10

# 配置 Trunk
interface GigabitEthernet0/0/24
port link-type trunk
port trunk allow-pass vlan 10 20 30

# 查看 MAC 表
display mac-address
```
