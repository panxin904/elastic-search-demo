# 5G 与移动网络

<div class="nt-badge nt-badge-wireless">无线网络</div>
<div class="nt-badge nt-badge-cloud">蜂窝</div>

5G 是第五代移动通信技术，定义了 eMBB（增强移动宽带）、mMTC（大规模物联网）、URLLC（超可靠低时延）三大场景。

## 1. 移动网络演进

| 代际 | 特点 | 速率 |
| --- | --- | --- |
| 1G | 模拟语音 | — |
| 2G (GSM) | 数字语音、短信 | 9.6 kbps |
| 3G (UMTS) | 移动数据 | 2 Mbps |
| 4G (LTE) | 全 IP，宽带 | 1 Gbps |
| 5G (NR) | 三大场景 | 10 Gbps |
| 6G (规划) | 通感一体 | 100 Gbps |

## 2. 5G 三大场景

| 场景 | 全称 | 应用 |
| --- | --- | --- |
| eMBB | enhanced Mobile BroadBand | 4K/8K 视频、VR |
| mMTC | massive Machine Type Communications | 智慧城市、传感 |
| URLLC | Ultra-Reliable Low-Latency | 自动驾驶、远程手术 |

## 3. 关键技术

| 技术 | 说明 |
| --- | --- |
| NR | New Radio，新空口 |
| OFDM | 正交频分复用 |
| Massive MIMO | 64/128/256 天线 |
| 波束赋形 | 定向波束 |
| mmWave | 毫米波（24~52 GHz） |
| Sub-6 GHz | 6 GHz 以下频段 |
| SA / NSA | 独立 / 非独立组网 |
| 网络切片 | 一张网切多张虚拟网 |
| 边缘计算 | MEC |

## 4. 频谱划分

| 频段 | 范围 | 特点 |
| --- | --- | --- |
| 低频 (FR1) | < 6 GHz | 覆盖好 |
| Sub-6 | 3.3 ~ 4.2 GHz | 中国主用 |
| 中频 | 2.6 / 3.5 GHz | 容量 + 覆盖 |
| 毫米波 (FR2) | 24 ~ 52 GHz | 高速短距 |

中国运营商频段：
- 中国移动：2.6 GHz + 4.9 GHz
- 中国电信：3.4 ~ 3.5 GHz
- 中国联通：3.5 ~ 3.6 GHz

## 5. 网络架构

```
UE（手机/IoT）
  ↕  Uu 空口
gNB（5G 基站）
  ↕  NG 接口
AMF / SMF / UPF（核心网）
  ↕
Internet / 数据网
```

| 网元 | 作用 |
| --- | --- |
| gNB | 5G 基站 |
| AMF | 接入与移动管理 |
| SMF | 会话管理 |
| UPF | 用户面转发 |
| AUSF/UDM | 认证 / 订阅 |
| PCF | 策略控制 |

## 6. 4G vs 5G 核心网

| 维度 | 4G EPC | 5G Core |
| --- | --- | --- |
| 架构 | 网元一体 | SBA 微服务 |
| 接口 | 私有 | HTTP/2 Service-Based |
| 切片 | 不支持 | 网络切片 |
| 边缘 | 难 | UPF 下沉 |
| 时延 | 50ms | < 10ms |

## 7. SA vs NSA

| 模式 | 含义 |
| --- | --- |
| NSA | 5G NR + 4G EPC，快速部署 |
| SA | 5G NR + 5GC，端到端 5G |

## 8. 网络切片

一张物理网络切出多个**逻辑独立**网络：

```
切片 1：手机用户（eMBB）
切片 2：车联网（URLLC）
切片 3：智慧城市（mMTC）
```

每切片独立 SLA、隔离、独立管理。

## 9. MEC（Multi-access Edge Computing）

- UPF / 计算下沉到基站侧
- 降低时延（< 5ms）
- 应用：CDN、本地渲染、车联网

## 10. SIM 卡演进

| 类型 | 特点 |
| --- | --- |
| 物理 SIM | 传统可拆卸 |
| eSIM | 嵌入式，可远程写号 |
| iSIM | 集成在 SoC，无实体卡 |

## 11. 移动场景优化

| 场景 | 优化 |
| --- | --- |
| 高速移动 | 切换时延、多基站协同 |
| 室内 | 飞基站、皮站、Sub-6 |
| 工业 | URLLC + 切片 |
| 农村 | 低频 700 MHz 覆盖 |

## 12. 常见面试题

1. **5G 三大场景？** eMBB、mMTC、URLLC。
2. **SA vs NSA？** SA 端到端 5G，NSA 借 4G EPC。
3. **毫米波特点？** 高速短距，易阻挡。
4. **网络切片？** 一张物理网切多张逻辑网。
5. **MEC 作用？** UPF 下沉，降时延。
6. **5G 时延？** URLLC < 1ms，eMBB < 4ms。
