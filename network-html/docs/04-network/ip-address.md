# IP 地址

<div class="nt-badge nt-badge-basics">网络层</div>
<div class="nt-badge nt-badge-network">核心</div>

IP（Internet Protocol）地址是分配给网络设备用于在 IP 网络中通信的唯一标识。本章系统讲解 IPv4 / IPv6、地址分类、子网划分、CIDR 等核心知识。

## 1. 什么是 IP 地址

| 特性 | 说明 |
| --- | --- |
| 作用 | 定位网络中的一台主机 / 路由器接口 |
| 层级 | 网络层（OSI 第 3 层） |
| 唯一性 | 在同一 IP 网络内必须唯一（公网 / 私网隔离） |
| 范围 | IPv4 32 bit、IPv6 128 bit |
| 分配 | 静态（管理员分配）/ 动态（DHCP） |

## 2. IPv4 地址格式

```
十进制表示：192.168.1.10
二进制表示：11000000.10101000.00000001.00001010
```

- 32 bit，分为 4 段（每段 8 bit / 1 byte）
- 每段取值 0~255
- 书写形式：**点分十进制**（dotted-decimal）

## 3. IPv4 地址分类（A/B/C/D/E）

| 类别 | 范围 | 网络位 | 主机位 | 默认掩码 | 用途 |
| --- | --- | --- | --- | --- | --- |
| A | 1.0.0.0 ~ 126.255.255.255 | 8 | 24 | 255.0.0.0 | 大型网络 |
| B | 128.0.0.0 ~ 191.255.255.255 | 12 | 16 | 255.255.0.0 | 中型网络 |
| C | 192.0.0.0 ~ 223.255.255.255 | 16 | 8 | 255.255.255.0 | 小型网络 |
| D | 224.0.0.0 ~ 239.255.255.255 | — | — | — | 组播 |
| E | 240.0.0.0 ~ 255.255.255.255 | — | — | — | 实验/保留 |

特殊地址：

| 地址 | 含义 |
| --- | --- |
| 0.0.0.0/0 | 默认路由 / 本机所有地址 |
| 127.0.0.0/8 | 回环（loopback），本机 |
| 169.254.0.0/16 | APIPA（DHCP 失败时自分配） |
| 255.255.255.255 | 本网络广播 |

## 4. 私有地址（RFC 1918）

| 类别 | 范围 | 用途 |
| --- | --- | --- |
| A | 10.0.0.0/8 | 大型企业 |
| B | 172.16.0.0/12 | 中型企业 |
| C | 192.168.0.0/16 | 家庭 / 小型办公 |

> 私有地址不可在公网路由，必须经 NAT 转换。

## 5. 子网掩码 & CIDR

- **子网掩码**：区分网络号与主机号，1 对应网络位，0 对应主机位
- **CIDR**（Classless Inter-Domain Routing）：用 `/n` 表示前缀长度

```
192.168.1.10/24  →  255.255.255.0
10.0.0.0/8       →  255.0.0.0
172.16.5.0/22    →  255.255.252.0
```

### 子网划分示例

将 `192.168.1.0/24` 平均划分为 4 个子网：

| 子网 | 网络地址 | 子网掩码 | 可用范围 | 广播 |
| --- | --- | --- | --- | --- |
| #0 | 192.168.1.0/26 | 255.255.255.192 | .1 ~ .62 | .63 |
| #1 | 192.168.1.64/26 | 255.255.255.192 | .65 ~ .126 | .127 |
| #2 | 192.168.1.128/26 | 255.255.255.192 | .129 ~ .190 | .191 |
| #3 | 192.168.1.192/26 | 255.255.255.192 | .193 ~ .254 | .255 |

## 6. IPv6 地址

```
2001:0db8:85a3:0000:0000:8a2e:0370:7334
```

- 128 bit，使用 8 组 16 进制，每组 4 个十六进制位
- 简化规则：
  - 每组前导 0 可省略
  - 连续全 0 组用 `::` 替代（**仅一次**）

```
2001:db8:85a3::8a2e:370:7334
::1                      // 回环（相当于 127.0.0.1）
fe80::/10                // 链路本地地址
```

| 类型 | 前缀 | 用途 |
| --- | --- | --- |
| 全局单播 | 2000::/3 | 公网 |
| 链路本地 | fe80::/10 | 同一链路 |
| 唯一本地 | fc00::/7 | 私网（替代 IPv4 私网） |
| 组播 | ff00::/8 | 一对多 |
| 回环 | ::1/128 | 本机 |

## 7. 公网 vs 私网

| 维度 | 公网 IP | 私网 IP |
| --- | --- | --- |
| 分配方 | IANA → ISP | 组织内部 |
| 唯一性 | 全球唯一 | 内部唯一即可 |
| 路由 | 可在 BGP 路由表中 | 不可路由 |
| 成本 | 收费 / 限量 | 免费 |
| 访问 | 可被公网访问 | 需 NAT |

## 8. 工具命令

```bash
# Linux
ip addr show                  # 查看本机 IP
ip route                      # 查看路由表
ip -4 addr show eth0          # 仅 IPv4
curl ifconfig.me              # 查看出口公网 IP

# macOS
ifconfig en0
networksetup -listallhardwareports

# Windows
ipconfig /all
```

## 9. 常见面试题

1. **IPv4 32 bit，最多多少个地址？** 2^32 ≈ 42.9 亿，已经枯竭。
2. **子网掩码的作用？** 区分网络号与主机号，决定同一 LAN 范围。
3. **192.168.1.1/24 主机数？** 2^8 - 2 = 254（去掉网络号与广播号）。
4. **IPv6 128 bit 够用吗？** 地址数 2^128 ≈ 3.4×10^38，号称能给地球上每粒沙子分配。
5. **CIDR 与 VLSM 区别？** CIDR 是聚合路由，VLSM 是把大网划成多个不等长子网，本质都是子网划分。

## 10. 一图速记

```
IPv4:   [ 网络号  |  主机号  ]  ← 子网掩码划分
IPv6:   全 128 bit，地址充足
公网 ⇄ 私网：经 NAT（网络地址转换）
广播：   IPv4 子网内 / IPv6 无广播只有组播
```
