# 子网划分与 VLSM

<div class="nt-badge nt-badge-network">网络层</div>
<div class="nt-badge nt-badge-interview">高频面试</div>

子网划分（Subnetting）是从一个大的 IP 段中拆出多个子网；VLSM（Variable Length Subnet Masking）允许同一网段内使用不同长度的子网掩码，让地址分配更精细。

## 1. 为什么要划分子网

| 目的 | 说明 |
| --- | --- |
| 减少广播域 | 每个子网独立广播，节省带宽 |
| 提升安全 | 部门间按子网隔离，便于 ACL 控制 |
| 节省地址 | 避免给 1000 人用 /16，导致大量浪费 |
| 便于管理 | 按楼层 / 部门 / 业务划分子网 |

## 2. 子网划分核心公式

| 公式 | 含义 |
| --- | --- |
| 子网数 = 2^n | n 为**借位**数 |
| 每子网主机数 = 2^m - 2 | m = 主机位（去网络号 + 广播号） |
| 新子网掩码 = 原掩码 + n 位 | 例：/24 → /26（借 2 位） |

## 3. 等长子网划分（传统 FLSM）

将 `192.168.10.0/24` 划分成 4 个等长子网：

| 子网 | 子网号 | 子网掩码 | 主机范围 | 广播地址 |
| --- | --- | --- | --- | --- |
| A | 192.168.10.0 | /26 | .1 ~ .62 | .63 |
| B | 192.168.10.64 | /26 | .65 ~ .126 | .127 |
| C | 192.168.10.128 | /26 | .129 ~ .190 | .191 |
| D | 192.168.10.192 | /26 | .193 ~ .254 | .255 |

每子网主机数 = 2^6 - 2 = 62。

## 4. VLSM 不等长子网

实际场景中部门规模不同，需要按需求分配不同大小的子网。

**示例**：公司拿到 `192.168.20.0/24`，要分配 4 个子网：

| 部门 | 主机数 | 需主机位 | 借位 | 子网 |
| --- | --- | --- | --- | --- |
| 研发部 | 100 | 7 → 2^7-2=126 | 1 (/25) | 192.168.20.0/25（126 台） |
| 市场部 | 50 | 6 → 2^6-2=62 | 2 (/26) | 192.168.20.128/26（62 台） |
| 财务部 | 20 | 5 → 2^5-2=30 | 3 (/27) | 192.168.20.192/27（30 台） |
| 行政部 | 10 | 4 → 2^4-2=14 | 4 (/28) | 192.168.20.224/28（14 台） |

> **原则**：从最大子网开始切，剩余地址继续切。

## 5. 超网（Supernetting / CIDR 聚合）

把多个小网聚合成大网，减小路由表项。

```
192.168.0.0/24
192.168.1.0/24
192.168.2.0/24
192.168.3.0/24
   ↓
192.168.0.0/22   ← 聚合 4 个 /24
```

聚合条件：必须是**连续**且**按位对齐**的子网。

## 6. 实战：计算可用 IP 范围

题目：主机 `10.0.5.123/19` 属于哪个子网？

- 19 位掩码：255.255.224.0
- 第 3 段块大小 = 2^(8-3) = 32
- 子网号：123 / 32 = 3 → 第 3 段起点 = 3 × 32 = 96
- 子网：**10.0.96.0/19**
- 可用范围：10.0.96.1 ~ 10.0.127.254
- 广播：10.0.127.255

## 7. 划分子网步骤（5 步法）

```
1. 确定需要多少个子网 → n
2. 找出满足 2^m >= n 的最小 m
3. 借位 = m，原掩码 + m = 新掩码
4. 计算块大小 = 2^(32-新前缀)
5. 从 0 开始按块大小递增，划出每个子网
```

## 8. 工具与脚本

```bash
# ipcalc 一行出结果
ipcalc 192.168.1.0/26
# Network:   192.168.1.0/26
# HostMin:   192.168.1.1
# HostMax:   192.168.1.62
# Broadcast: 192.168.1.63

# Python 一行切分
python3 -c "import ipaddress; [print(n) for n in ipaddress.ip_network('192.168.1.0/24').subnets(new_prefix=26)]"
```

## 9. 常见面试题

1. **/24 与 /25 区别？** /24 256-2=254 台主机，/25 128-2=126 台主机。
2. **VLSM 与 FLSM 区别？** FLSM 等长子网，VLSM 不等长子网，VLSM 更省地址。
3. **172.16.10.5/22 所属子网？** 块大小 4，第 3 段 5/4=1 → 172.16.8.0/22。
4. **/31 有什么用？** 仅 2 地址，用于点对点链路（如路由器之间），RFC 3021。
5. **/32 是什么？** 主机路由（host route），指向单台设备。
