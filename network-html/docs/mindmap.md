# 思维导图

<div class="nt-badge nt-badge-network">导图</div>
<div class="nt-badge nt-badge-interview">结构化</div>

通过交互式思维导图，**结构化**梳理计算机网络知识体系。

<MindMap />

## 使用说明

- 鼠标拖动：移动画布
- 点击节点：展开/折叠子节点
- 滚轮：缩放
- 顶部按钮：全部展开、全部折叠、重置视角

## 导图结构

```
计算机网络
├── 1. 网络基础
│   ├── OSI 七层
│   ├── TCP/IP 四层

│   └── 性能指标

│   ├── 信号与编码
│   ├── 传输介质

│   ├── 以太网
```
