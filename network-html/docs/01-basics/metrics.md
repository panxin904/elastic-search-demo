# 📊 网络性能指标

> 评估网络质量的**关键度量**，是性能优化的基础。

## 🎯 四大核心指标

| 指标 | 英文 | 含义 | 公式 |
|---|---|---|---|
| **带宽** | Bandwidth | 最大传输速率 | bps（bit/s）|
| **吞吐量** | Throughput | 实际传输速率 | bps |
| **延迟** | Latency | 数据传输时间 | ms |
| **丢包率** | Packet Loss | 丢失包占比 | % |

## 📊 带宽 vs 吞吐量

```
带宽（理论上限）        吞吐量（实际可达）
┌──────────────┐      ┌──────────────┐
│              │      │    ┌──┐      │
│  1 Gbps      │  ──→ │    │  │      │
│              │      │    └──┘      │
│              │      │  600 Mbps    │
└──────────────┘      └──────────────┘
   理论最大值            实际能力（受协议、干扰等影响）
```

**单位：**
- bps = bit per second
- Bps = Byte per second（1 Bps = 8 bps）

## ⏱ 延迟详解

**延迟 = 发送延迟 + 传播延迟 + 处理延迟 + 排队延迟**

### 1. 发送延迟（Transmission Delay）

```
发送延迟 = 数据长度(bits) / 带宽(bps)

例：1 MB 文件，100 Mbps 带宽
   = 8,000,000 / 100,000,000 = 0.08s = 80ms
```

### 2. 传播延迟（Propagation Delay）

```
传播延迟 = 距离 / 传播速度

例：1000 km 光纤，传播速度约 2×10^8 m/s
   = 1,000,000 / 200,000,000 = 5ms
```

### 3. 处理延迟（Processing Delay）

```
路由器检查包头、查路由表等
一般 < 1ms
```

### 4. 排队延迟（Queuing Delay）

```
在路由器队列中等待时间
拥塞时可达几十 ms
```

### 总延迟

```
RTT（往返时延）= 去程 + 回程
例：北京 → 上海 RTT ≈ 30ms
```

## 📈 测量延迟工具

```bash
# ping - 测试 RTT
ping www.example.com
# 输出：time=23.4 ms

# traceroute - 路径追踪
traceroute www.example.com
# 显示每一跳延迟

# mtr - 综合工具
mtr -r -c 10 www.example.com

# tcpping - TCP 端口延迟
tcping -p 80 www.example.com

# iperf3 - 带宽测试
iperf3 -c server_ip
```

## ⚡ 延迟分级

| 延迟 | 用户体验 |
|---|---|
| < 30 ms | 优秀（本地操作）|
| 30-100 ms | 良好（普通网络）|
| 100-200 ms | 可接受（远程操作）|
| > 200 ms | 差（明显卡顿）|
| > 500 ms | 极差（无法交互）|

## 📉 丢包率与重传

```
发送 100 个包，收到 97 个 → 丢包率 3%
```

**影响：**
- TCP：触发重传，延迟增加
- UDP：不重传，直接丢失（语音、视频卡顿）

**丢包原因：**
- 网络拥塞
- 设备故障
- 信号干扰（无线）
- 路由抖动

**检测命令：**
```bash
# 长时间 ping 看丢包
ping -c 1000 www.example.com
# 统计：1000 packets transmitted, 998 received, 0.2% packet loss
```

## 🚀 性能优化关键指标

### QoS（Quality of Service）

| 类型 | 适用 | 优先级 |
|---|---|---|
| 语音（VoIP）| 实时 | 最高 |
| 视频会议 | 实时 | 高 |
| 在线游戏 | 实时 | 高 |
| 网页浏览 | 交互 | 中 |
| 文件下载 | 批量 | 低 |
| 邮件 | 非实时 | 最低 |

### 网络质量度量

| 指标 | 英文 | 含义 |
|---|---|---|
| **抖动** | Jitter | 延迟的变化幅度 |
| **MOS** | Mean Opinion Score | 主观语音质量评分 |
| **PSQA** | Pseudo-Subjective Quality | 客观语音质量评估 |

**抖动示例：**
```
延迟序列：20ms, 25ms, 18ms, 30ms, 22ms
抖动 = max - min = 12ms
```

## 📊 网络性能排查流程

```
1. 测试基础连通性 → ping
2. 测试带宽 → iperf3
3. 追踪路径 → traceroute
4. 查看丢包 → mtr
5. 抓包分析 → Wireshark
6. 查看路由表 → route -n
7. 查看连接状态 → ss / netstat
```

## 🛠️ 性能优化技巧

| 优化方向 | 方法 |
|---|---|
| **减少延迟** | CDN、边缘计算、BGP Anycast |
| **提升带宽** | 升级网络、负载均衡、压缩 |
| **减少丢包** | QoS 优先级、QoS 队列 |
| **减少抖动** | 流量整形 (Traffic Shaping) |
| **协议优化** | TCP 调参、QUIC、HTTP/2 多路复用 |

| RTT 是什么？| 往返时延 = 去程 + 回程 |
| 怎么测带宽？| iperf3、speedtest |
