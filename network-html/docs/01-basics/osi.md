# 🌐 OSI 七层模型

> 国际标准化组织（ISO）提出的**网络通信参考模型**，是理解计算机网络的基石。

## 🎯 七层架构

```
┌─────────────────────────────────────────────┐
│ 7. 应用层    │ HTTP / DNS / FTP / SMTP       │ ← 用户接口
├─────────────────────────────────────────────┤
│ 6. 表示层    │ 加密 / 压缩 / 编码转换        │ ← 数据格式
├─────────────────────────────────────────────┤
│ 5. 会话层    │ 建立 / 维护 / 终止会话         │ ← 会话管理
├─────────────────────────────────────────────┤
│ 4. 传输层    │ TCP / UDP / 端口 / 段          │ ← 端到端
├─────────────────────────────────────────────┤
│ 3. 网络层    │ IP / 路由 / 子网               │ ← 主机到主机
├─────────────────────────────────────────────┤
│ 2. 数据链路层 │ MAC / 帧 / 交换机 / VLAN       │ ← 相邻节点
├─────────────────────────────────────────────┤
│ 1. 物理层    │ 比特流 / 网线 / 光纤 / 电信号  │ ← 物理介质
└─────────────────────────────────────────────┘
```

## 📋 各层职责

| 层 | 名称 | 数据单位 | 主要协议/设备 | 功能 |
|---|---|---|---|---|
| 7 | 应用层 | 报文 | HTTP, DNS, FTP, SMTP | 用户接口、网络服务 |
| 6 | 表示层 | 报文 | SSL/TLS, JPEG, ASCII | 数据表示、加密 |
| 5 | 会话层 | 报文 | NetBIOS, RPC | 会话管理、同步 |
| 4 | 传输层 | 段 | TCP, UDP | 端到端、端口、可靠传输 |
| 3 | 网络层 | 包 | IP, ICMP, ARP, 路由器 | 路由寻址、转发 |
| 2 | 数据链路层 | 帧 | Ethernet, PPP, 交换机 | 帧同步、差错控制 |
| 1 | 物理层 | 比特 | 网线、光纤、集线器 | 比特流传输 |

## 🎯 记忆口诀

```
"物数网传会表应"
（物理 → 数据链路 → 网络 → 传输 → 会话 → 表示 → 应用）
```

或倒序：**"应表会传网数物"**

## 🔄 数据传输过程

```
发送方（自顶向下）              接收方（自底向上）
   应用层   ──── 封装 ────→    应用层
   表示层                          │
   会话层                          ↓
   传输层                       传输层
   网络层  ←─ 加上 IP 头 ─    网络层
   链路层  ←─ 加上 MAC 头 ─   链路层
   物理层  ←─ 转比特流 ─     物理层 ──── 解封装 ────→
```

**举例：访问 https://www.example.com**
1. 应用层：浏览器发起 HTTP 请求
2. 表示层：TLS 加密
3. 传输层：加上 TCP 头部（端口 443）
4. 网络层：加上 IP 头部（目标 IP）
5. 数据链路层：加上 MAC 头部（目标 MAC 通过 ARP 获取）
6. 物理层：转换为电信号/光信号传输

## 📊 OSI vs TCP/IP

| 维度 | OSI（7 层）| TCP/IP（4 层）|
|---|---|---|
| 来源 | ISO 标准 | 实际协议族 |
| 应用层 | 应用 + 表示 + 会话 | 应用层 |
| 传输层 | 传输层 | 传输层 |
| 网络层 | 网络层 | 网际层 |
| 链路层 | 数据链路 + 物理 | 网络接口层 |
| 应用 | 理论参考 | 实际使用 |

## ⚡ 各层典型设备

| 层 | 设备 |
|---|---|
| 物理层 | 中继器、集线器（Hub）|
| 数据链路层 | 网桥、交换机（Switch）|
| 网络层 | 路由器（Router）、三层交换机 |
| 传输层 | 负载均衡器、防火墙 |
| 应用层 | 网关、代理服务器 |

## 🎓 面试高频问题

| 问题 | 关键点 |
|---|---|
| 七层模型是哪七层？| 物数网传会表应（自下而上）|
| 每层的数据单位？| 比特/帧/包/段/报文 |
| TCP 在哪一层？| 传输层 |
| IP 在哪一层？| 网络层 |
| HTTP 在哪一层？| 应用层 |
