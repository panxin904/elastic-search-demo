# 学习路径

<span class="kg-badge kg-badge-basics">路径</span>
<span class="kg-badge kg-badge-interview">指南</span>

按角色和目标提供**结构化学习路径**，从入门到精通逐步进阶。

## 🎯 5 大目标路径

### 🟢 入门路径（2 周）

适合：视频相关岗位入门 / 转行

```
视频基础
  ├─ 视频本质 / 像素与帧
  ├─ 色彩空间 YUV/RGB
  ├─ 分辨率 / 帧率 / 码率
  └─ 容器格式 MP4/MKV
编解码概览
  └─ 帧内/帧间预测基本概念
FFmpeg 入门
  ├─ 基础命令
  ├─ 格式转换
  └─ 裁剪 / 拼接
```

### 🔵 音视频工程师（2-3 月）

适合：客户端音视频 / 视频处理开发

```
入门路径
  ↓
编解码原理
  ├─ 帧内预测 / 帧间预测
  ├─ DCT 变换与量化
  ├─ 熵编码 CABAC/CAVLC
  └─ 运动估计与补偿
主流编码标准
  ├─ H.264/AVC（必掌握）
  ├─ H.265/HEVC
  └─ AV1（了解）
FFmpeg 进阶
  ├─ 滤镜图
  ├─ 复杂编码参数
  └─ 性能调优
视频算法
  ├─ 缩放 / 去噪
  └─ 超分辨率
性能优化
  ├─ NVENC/QSV 硬件加速
  └─ 多线程
```

### 🟡 直播开发（1-2 月）

适合：直播 SDK / 直播平台开发

```
视频基础 → 编解码概览
  ↓
流媒体协议（重点）
  ├─ RTMP（推流）
  ├─ HLS / DASH（点播切片）
  ├─ WebRTC（实时互动）
  └─ RTSP / SRT（监控/广电）
CDN 分发架构
  ├─ 推流 → 边缘 → 播放
  ├─ 转码集群
  └─ 多协议输出
应用场景
  ├─ 直播
  └─ 视频会议
云视频服务
  ├─ 阿里云 MPS
  └─ 腾讯云直播
企业案例
  └─ B 站 / 抖音 / 腾讯直播
```

### 🟣 AI 算法工程师（1-3 月）

适合：视频 AI / 计算机视觉

```
视频基础 → 编解码原理
  ↓
视频算法
  ├─ 传统算法（缩放 / 去噪）
  ├─ 帧率转换（运动估计）
  └─ 超分辨率原理
AI 视频处理
  ├─ AI 超分（Real-ESRGAN / Video2X）
  ├─ AI 插帧（RIFE / FILM）
  ├─ 视频修复
  ├─ 视频分割（SAM2 / SAM-V）
  ├─ 视频生成（Sora / Runway / Pika）
  ├─ 数字人（HeyGen / D-ID）
  └─ 唇形同步（Wav2Lip）
性能优化
  └─ GPU CUDA
应用场景
  └─ 短视频 / 影视后期
企业案例
  └─ 抖音 / B 站 AI
```

### 🔴 面试突击（2 周）

适合：求职音视频岗位

```
高频面试题（48 道）
  ├─ 编解码原理
  ├─ H.264 vs H.265
  ├─ FFmpeg 常用命令
  ├─ RTMP vs HLS vs WebRTC
  ├─ 视频处理算法
  └─ AI 视频
场景案例题
  ├─ 设计直播系统
  ├─ 设计视频转码集群
  ├─ AI 视频生成系统
  └─ CDN 优化
协议对比表
  ├─ RTMP/HLS/WebRTC
  ├─ H.264/H.265/AV1
  ├─ NVENC/QSV/VAAPI
  └─ GOP / 帧率 / 码率
```
