# 帧内预测（Intra Prediction）

<span class="kg-badge kg-badge-codec">原理</span>
<span class="kg-badge kg-badge-codecs">I 帧</span>

利用**同一帧内**相邻像素的相关性进行预测，是 I 帧压缩的核心。

## 🧠 基本思想

```
已知: 已编码的左邻 A、上邻 B、左上 C、右上 D
预测: 当前块 X 的像素

预测值 = 某个方向的预测模式
残差   = 原值 - 预测值
传输: 预测模式 + 残差
```

## 📐 H.264 帧内预测模式（9 种）

| 模式 | 名称 | 预测方向 |
| --- | --- | --- |
| **0** | Intra_4x4_Vertical | 垂直 |
| **1** | Intra_4x4_Horizontal | 水平 |
| **2** | Intra_4x4_DC | 平均 |
| **3** | Intra_4x4_Diagonal_Down_Left | 左下对角 |
| **4** | Intra_4x4_Diagonal_Down_Right | 右下对角 |
| **5** | Intra_4x4_Vertical_Right | 垂直偏右 |
| **6** | Intra_4x4_Horizontal_Down | 水平偏下 |
| **7** | Intra_4x4_Vertical_Left | 垂直偏左 |
| **8** | Intra_4x4_Horizontal_Up | 水平偏上 |

> 4×4 块共 9 种模式；8×8 块 9 种；16×16 块 4 种（垂直/水平/DC/Plane）

## 🔬 帧内预测流程

```
1. 当前 CTU/CU
2. 已重建的左邻 / 上邻像素（参考样本）
3. 计算每个模式的 SAD/SATD 代价
4. 选择代价最小的模式作为最佳预测
5. 原值 - 预测值 = 残差
6. 残差 → DCT → 量化 → 熵编码
```

## 📊 编码复杂度

| 编码 | 模式数 | 计算量 |
| --- | --- | --- |
| H.264 4×4 | 9 | 低 |
| H.264 8×8 | 9 | 中 |
| H.264 16×16 | 4 | 低 |
| H.265 | 35 | **高** |
| AV1 | 56+ | **极高** |

## 💡 RDO 模式选择

**率失真优化**（Rate-Distortion Optimization）

```
J = D + λ × R

D = 失真（SSD/SAD）
R = 比特率
λ = 拉格朗日乘子

选择 J 最小的模式
```

## 🎯 编码工具

| 工具 | 用途 |
| --- | --- |
| **RDOQ** | 率失真优化量化 |
| **Mode Skip** | 跳过相似块 |
| **Merge Mode** | 共享 MV（H.265） |
| **MIP** | 矩阵化帧内预测（VVC） |
| **CCSO** | 跨分量样本偏移（VVC） |

## 📌 面试考点

1. 帧内预测为什么有效？
   - 同一帧内相邻像素高度相关
2. H.265 为什么用更多预测模式？
   - 块更大、模式更多，提高压缩率
3. RDO 是什么？
   - 率失真优化，综合码率和失真
4. Planar 模式用途？
   - 平滑渐变区域（天空、墙面）
