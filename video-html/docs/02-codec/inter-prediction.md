# 帧间预测（Inter Prediction）

<span class="kg-badge kg-badge-codec">原理</span>
<span class="kg-badge kg-badge-codecs">P / B 帧</span>

利用**相邻帧**之间的高度相似性，通过**运动估计 + 运动补偿**去除时间冗余。

## 🧠 基本思想

```
帧 N (当前):  待编码
帧 N-1 (参考): 已重建

对帧 N 的每个块：
  在帧 N-1 中搜索最佳匹配块
  记录运动矢量 MV (dx, dy)
  预测值 = 帧 N-1 中对应位置像素
  残差 = 帧 N - 预测值
  传输 MV + 残差
```

## 📊 帧间预测类型

| 类型 | 参考帧 | 数量 | 压缩率 |
| --- | --- | --- | --- |
| **P 帧** | 前 1 帧 | 1 个 | 中 |
| **B 帧** | 前 + 后 | 2 个 | **最高** |
| **多参考 B** | 多个参考帧 | 最多 16 | 更高 |

## 📐 块划分

### H.264

```
16×16 ──┬─ 16×8
        ├─ 8×16
        └─ 8×8 ─── 8×8 ──┬─ 8×4
                          ├─ 4×8
                          └─ 4×4

最小 4×4，最大 16×16
```

### H.265/HEVC

```
CTU (64×64) → CU (4×4 ~ 64×64) → PU / TU

支持四叉树划分 + 不对称划分:
  2N×2N / 2N×N / N×2N / N×N
  2N×nU / 2N×nD / nL×2N / nR×2N
```

### AV1

```
支持更多块形状 + 递归划分深度
最小 4×4，最大 128×128
```

## 🎯 运动估计（ME）

### 搜索算法

| 算法 | 复杂度 | 性能 |
| --- | --- | --- |
| **全搜索** | 极高 | 最优 |
| **三步法（TSS）** | 中 | 较优 |
| **菱形搜索（DS）** | 低 | 优 |
| **六边形搜索** | 低 | 优 |
| **EPZS** | 低 | 优 |
| **UMH** | 中 | 优 |

### 匹配准则

```
SAD  = Σ |A - B|             // 最快
SSD  = Σ (A - B)²            // 准确
SATD = Σ |DCT(A - B)|         // 较好（考虑频域）
```

## 🎯 运动补偿（MC）

```
预测值 P(x, y) = R(x + MVx, y + MVy)

亚像素插值:
  1/2 像素: 6-tap 滤波器 (H.264/HEVC)
  1/4 像素: 双线性插值 (H.264)
  1/8 像素 (AV1)
```

## 📊 运动矢量预测

| 技术 | 编码 |
| --- | --- |
| **MVP** | 中值预测（H.264/HEVC） |
| **AMVP** | 高级运动矢量预测（H.265） |
| **Merge/Skip** | 直接复用邻块 MV（无需传 MV） |
| **OBMC** | 重叠块运动补偿（H.263） |
| **Wedge** | 双向预测权重（VVC） |

### H.265 MV 预测候选

| 候选 | 来源 |
| --- | --- |
| A1 | 左邻块 MV |
| B1 | 上邻块 MV |
| B0 | 右上块 MV |
| A0 | 左下块 MV |
| B2 | 时间共位块 MV（Merge） |

## 🎯 双向预测（B 帧）

```
B 帧块 = α × 前向参考 + β × 后向参考
        = α × R0(x + MV0x, y + MV0y)
        + β × R1(x + MV1x, y + MV1y)

α + β = 1（加权）
```

## 📈 B 帧对压缩率的提升

```
无 B 帧: I P P P P P P   →  100%
有 B 帧: I P B B B B P   →  ~70% (~30% 节省)
多 B 帧: I P B B B B B B P  →  ~50% (~50% 节省)
```

## ⚠️ B 帧的延迟问题

```
显示顺序: I1 B2 B3 P4 B5 B6 P7
编码顺序: I1 P4 B2 B3 P7 B5 B6
         ↑    ↑  ↑  ↑  ↑  ↑  ↑
         必须先编码 P4 才能编码 B2/B3

→ B 帧越多，编码延迟越高（实时场景慎用）
```

## 📌 面试考点

1. P 帧和 B 帧的区别？
   - P 帧单向前向参考，B 帧双向参考
2. 为什么 B 帧压缩率高但延迟大？
   - 双向参考需要前后帧都编码完
3. 运动矢量的作用？
   - 记录块的运动方向和距离
4. Merge Mode 是什么？
   - 直接复用邻块 MV，无需单独编码 MV
