# 环路滤波（Loop Filter）

<span class="kg-badge kg-badge-codec">原理</span>
<span class="kg-badge kg-badge-codecs">后处理</span>

编码环路中的**重建滤波器**，消除块效应、提升主观画质。

## 🧠 为什么需要环路滤波？

```
原始图像: 平滑过渡
     ↓ 块划分 / 量化 / 运动补偿
重建图像: 块边界不连续（块效应）

      块1 │ 块2
    ─────┼─────
    200  │ 195   ← 边界不连续
    ─────┼─────
    200  │ 195

环路滤波后: 平滑过渡
```

## 🔬 三大滤波技术

| 滤波 | 编码 | 特点 |
| --- | --- | --- |
| **去块滤波 (DF)** | H.264/H.265 | 必备，平滑块边界 |
| **样点自适应补偿 (SAO)** | H.265 | 可选，补偿振铃 |
| **ALF 自适应环路滤波** | H.265/VVC | 可选，Wiener 滤波 |
| **CCSAO** | VVC | 跨分量 SAO |
| **LMCS** | VVC | 亮度映射色度缩放 |

## 📐 去块滤波（Deblocking Filter）

### 原理

```
对每个块边界：
  检测是否为「真边界」或「块效应」
  - 真边界：保留（场景内容）
  - 块效应：平滑掉

根据 QP 和边界强度 Bs 选择滤波强度
```

### 边界强度 BS

| BS | 条件 | 滤波强度 |
| --- | --- | --- |
| 0 | 无预测残差 | 不滤波 |
| 1 | P 或 B 帧 | 弱滤波 |
| 2-3 | 帧间残差 | 强滤波 |
| 4 | 帧内边界 | 最强滤波 |

### 滤波器

```
边界两侧像素: P2 P1 P0 | Q0 Q1 Q2

弱滤波（边界仅 ±1）:
  P0' = (P0 + 2P1 + 2P0 + Q0 + 4) / 8
  Q0' = (Q0 + 2Q0 + 2Q1 + P0 + 4) / 8

强滤波（边界 ±2）:
  P0' = (2P1 + P0 + Q0 + 2) / 4
  P1' = (3P2 + P1 + P0 + Q0 + 4) / 8
  ...
```

## 📐 SAO（样点自适应补偿）

H.265 在去块滤波之后可选。

### 模式

| 模式 | 含义 |
| --- | --- |
| **OFF** | 不补偿 |
| **Band Offset** | 按像素值范围补偿 |
| **Edge Offset** | 按边缘方向补偿（0/90/135/45） |

### Band Offset

```
像素值分 32 个 band
对每个 band 加上/减去偏移量

例：某 band 普遍偏暗 → 加 +5
```

### Edge Offset（4 个方向）

```
水平 (0°): 检测垂直边缘
垂直 (90°): 检测水平边缘
135°: 检测 ↗ 方向
45°: 检测 ↘ 方向

按边缘类别:
  - 局部最小 → 加偏移
  - 局部最大 → 减偏移
```

## 📐 ALF（自适应环路滤波）

H.265 / VVC 使用 Wiener 滤波器。

```
y[n] = Σ w[k]·x[n-k]

滤波器系数 w 通过最小化 MSE 学习
```

| 维度 | H.265 | VVC |
| --- | --- | --- |
| 形状 | 5×5 十字 | 7×7 / 9×9 |
| 系数 | 13 | 13 |
| 分类 | 25 类 | 32 类 |

## 📐 LMCS（亮度映射与色度缩放）

**VVC/H.266 引入**，解决 HDR 映射问题。

```
输入亮度
  ↓
[分段线性映射] L_in → L_out
  ↓
输出码流

色度按亮度范围缩放
```

## 📊 滤波顺序

```
解码流程:
  比特流
    ↓
  熵解码 / 反量化 / IDCT
    ↓
  预测补偿
    ↓
  重建块
    ↓
  ┌─ 去块滤波 (DF)  ← 必备
  │
  ├─ SAO          ← H.265 可选
  │
  └─ ALF          ← H.265 可选
    ↓
  输出 YUV
```

## 🛠️ FFmpeg 控制

```bash
# 关闭去块
ffmpeg -i in.mp4 -c:v libx264 -x264-params "deblock=-3,-3" out.mp4

# 强去块
ffmpeg -i in.mp4 -c:v libx264 -x264-params "deblock=1,1" out.mp4

# 关闭 SAO
ffmpeg -i in.mp4 -c:v libx265 -x265-params "sao=0" out.mp4

# 关闭 ALF
ffmpeg -i in.mp4 -c:v libx265 -x265-params "alf=0" out.mp4
```

## 📌 面试考点

1. 块效应是怎么产生的？
   - 独立量化导致块边界不连续
2. 去块滤波和 SAO 区别？
   - DF 平滑块边界；SAO 补偿像素值
3. 环路滤波在编码端还是解码端？
   - **两端都有**，必须一致
4. ALF 和 Wiener 滤波关系？
   - ALF 是自适应 Wiener 滤波
