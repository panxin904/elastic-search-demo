## 📤 上传服务

### 客户端上传

```javascript
// B 站分片上传（简化）
const upload = async (file) => {
    const uploadId = await fetch('/api/upload/init').json();

    const chunkSize = 4 * 1024 * 1024; // 4MB
    const parts = [];
    for (let i = 0; i < file.size; i += chunkSize) {
        const chunk = file.slice(i, i + chunkSize);
        const etag = await uploadChunk(uploadId, i, chunk);
        parts.push({partNumber: i, etag});
    }

    return await fetch('/api/upload/finish', {
        method: 'POST',
        body: JSON.stringify({uploadId, parts})
    });
};
```

### 高速上传技术

| 优化 | 描述 |
| --- | --- |
| **P2P 加速** | 大文件多用户共享上传 |
| **多线程分片** | 客户端 4-8 线程并发上传 |
| **智能分片** | 根据网络状况调整分片大小 |
| **弱网重试** | 局部失败不重传整文件 |
| **断点续传** | 上传中断后无缝恢复 |

| 分辨率 | 编码 | 视频码率 | 音频 | 备注 |

| 4K | H.265 | 6000k | 320k | 超清大会员 |

| 720p | H.264 | 1500k | 192k | 标清 |
| 480p | H.264 | 800k | 192k | 流畅 |
| 360p | H.264 | 400k | 128k | 省流 |
| 240p | H.264 | 200k | 96k | 极省流 |

### B 站 H.265 / AV1 推广

B 站在 4K、大会员专享部分采用 **H.265** 编码：
- 节省 30-50% 带宽
- 适配 TV / 高端移动设备

部分浏览器场景试用 **AV1**。

## 💾 存储系统

### 对象存储 + 自研 BOS

B 站使用自研对象存储 **BOS（Bilibili Object Storage）**：

- PB 级
- 多副本 + Erasure Coding
- HDFS + 自研适配
- 高带宽、低延迟

### 存储分层

| 数据 | 存储 | 生命周期 |
| --- | --- | --- |
| **热数据** | SSD | 当天 |
| **温数据** | HDD | 30 天 |
| **冷数据** | 归档 | 永久（极少访问） |
| **原片** | 归档 + HSM | 长期保存 |

### 数据冗余

- 跨机房副本
- Erasure Coding (Reed-Solomon)
- 异地灾备

## 🤖 AI 审核

### 内容审核流程

```
用户上传 → AI 机审
              ├── 文本审核
              │   ├── 评论敏感词
              │   ├── 弹幕敏感词
              │   ├── OCR 字幕 / 标题
              │   └── 简介 + 标签
              ├── 图像审核
              │   ├── 封面检测
              │   ├── 关键帧抽帧
              │   ├── 色情 / 暴力 / 政治识别
              │   └── 知名人物识别
              └── 音频审核
                  ├── ASR 转写
                  ├── 敏感词检测
                  └── 声纹比对

↓ 通过 → 用户可见
↓ 风险高 → 人工复审
↓ 明确违规 → 直接屏蔽
```

### 自研 AI 模型

B 站有自研的 AI 模型做内容理解：
- **图像分类**：视频分类、标签预测
- **NLP**：弹幕情感分析
- **OCR**：视频内文字提取
- **语音**：语音转文字
- **明星识别**：人脸识别
