# 腾讯直播 (LVB / 互动直播) 架构

<span class="kg-badge kg-badge-cases">案例</span>
<span class="kg-badge kg-badge-cloud">直播</span>
<span class="kg-badge kg-badge-protocol">互动</span>

腾讯云 LVB（Live Video Broadcasting）是商业化直播服务，提供 **标准直播、快直播（WebRTC）、慢直播（接近延时）** 等能力，覆盖 **游戏 / 带货 / 教育 / 体育** 场景。

## 🏗️ 腾讯云直播总体架构

```
┌─────────────────────────────────────────────────────┐
│ 推流端 (推流 SDK / OBS / 编码器)                      │
├─────────────────────────────────────────────────────┤
│ 接入层                                              │
│ 全球 RTMP / WebRTC / SRT 接入节点                       │
├─────────────────────────────────────────────────────┤
│ 实时媒体处理                                          │
│ 转码集群 / 录制集群 / 截图 / 审核 / 水印                │
├─────────────────────────────────────────────────────┤
│ 互动 + AI                                            │
│ 弹幕 IM / 连麦 / 礼物特效 / AI 数字人                  │
├─────────────────────────────────────────────────────┤
│ 分发层                                              │
│ 200+ CDN 节点 / 全球加速 / QUIC 优化                   │
└─────────────────────────────────────────────────────┘
```

## 📡 多协议支持

### 标准直播（FLV/HLS）

```
RTMP 推流 → 接入层
              ├── FLV (HTTP-FLV) → 端上拉流
              ├── HLS → 端上拉流 / Web 拉流
              └── 录制 → 对象存储 VOD
```

### 快直播（超低延迟 WebRTC / LLVision）

```
WebRTC 推流 → 接入层
            ├── WebRTC 拉流（< 800ms）
            └── 兼容 RTMP/HLS
```

### 慢直播（接近延时，可恢复）

- 通过定时截图 + 转码
- 极低成本，海量并发

## 🎥 转码与处理

### 转码能力

- 多分辨率输出（流畅 / 标清 / 高清 / 超清）
- H.264 / H.265 / AV1 编码
- 实时水印 / 字幕 / 转场

### AI 增强

- **极速高清**：同等画质 30-50% 节省
- **AI 修图**：直播实时美颜
- **AI 字幕**：实时 ASR + 翻译
- **数字人直播**：虚拟主播实时驱动

## 📡 直播回放 / 点播一体化

```
直播录制 → VOD (点播) → 自适应码率 (ABR) → 点播播放
   ↓                        ↓                    ↓
 云点播系统              HLS / DASH             全平台
```

### 自动录制

- 按流录制（推流就开始录）
- 录制后可自动转码
- 录制 + 字幕 + AI 标签

## 💬 互动能力

### IM 系统

```
WebSocket 接入 → 消息分发 → 房间路由
                                    ↓
                       ├── 弹幕
                       ├── 礼物
                       ├── 点赞
                       └── 系统通知
```

### 连麦互动

```
主播 A ←── SFU ──→ 主播 B
                  ↓
              观众 (同时观看 A + B)
```

支持多种互动：
- PK（双人连麦）
- 多人连麦（会议模式）
- 观众上麦

## 📱 客户端 SDK

### 移动端 SDK

```swift
// iOS TXLivePlayer
let player = TXLivePlayer()
let url = "http://example/live/test.flv"
player.startPlay(url, type: .PLAY_TYPE_LIVE_FLV)
player.enableHardwareDecoding(true)

// 推流（TXLivePusher）
let pusher = TXLivePusher()
pusher.startCameraPush("rtmp://example/live/test", listener: ...)
```

### Web SDK

```javascript
// tcplayer
const player = TCPlayer('player-container-id', {
    sources: [{
        src: 'http://example/live/test.flv',
        type: 'flv'
    }]
});
player.play();

// 弹幕
const danmaku = player.danmaku();
danmaku.send('hello');
```

## 🤖 AI 数字人直播

```
商品 + 场景脚本
   ↓

   ↓

   ↓
口型同步生成视频流
   ↓
推到腾讯直播
   ↓
观众端播放
```

## 🔧 性能优化要点

### 推流端

- **硬编优先**（VideoToolbox / MediaCodec）
- **码率自适应**（网络探测）
- **错误重连**（断线重连 + GOP 缓存）

### 服务端

- **就近接入**（IP 地理位置）
- **多 CDN 调度**（智能 + 故障切换）
- **GPU 转码**（高并发低延迟）

### 拉流端

- **HTTP-FLV**（FLV over HTTP）
- **HLS**（跨平台）
- **WebRTC**（超低延迟）
- **QUIC**（弱网优化）

## 📚 实战最佳实践

1. **多 CDN 混合**：避免单点
2. **推流 SDK**：用官方 TXLivePusher
3. **Web 拉流**：HTTP-FLV + hls.js 兼容
4. **录制**：自动开启 + 自动切片点播
5. **互动**：用 IM + 礼物特效组件
6. **AI 数字人**：技术成熟、成本低
7. **监控**：实时仪表 + 告警
8. **限流保护**：按业务配置 QPS
