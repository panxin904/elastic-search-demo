## 📤 上传优化

### 客户端特性

- **多线程分片**：4-8 线程并发上传
- **断点续传**：失败局部重传
- **全球加速**：根据地理区域选择最近接入点
- **网络切换容忍**：WiFi / 移动网络无缝切换

### 视频预处理

```cpp
// 客户端上传前预处理
class VideoPreprocessor {
public:
    void process(const string& input) {
        // 1. 转码 H.265 (压缩比高)
        reencode_h265(input, output_h265, 2500);

        // 2. 客户端 AI 标签
        ai_tags = runClientModel(output_h265);
        //    ├── 风景 / 人物 / 物体
        //    ├── 美学评分
        //    └── 内容审核预筛

        // 3. 客户端 smart codec 优化
        optimize_codec(output_h265);

        // 4. 多分辨率剪裁
        generateMultiResolution(input, sizes);
    }
};
```
