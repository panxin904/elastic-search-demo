# 思维导图

<span class="kg-badge kg-badge-basics">导图</span>
<span class="kg-badge kg-badge-cases">结构化</span>

通过交互式思维导图，**结构化**梳理视频处理知识体系。

<MindMap />

## 使用说明

- 鼠标拖动：移动画布
- 点击节点：展开/折叠子节点
- 滚轮：缩放
- 顶部按钮：全部展开、全部折叠、重置视角
