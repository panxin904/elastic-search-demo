# H.265 / HEVC（高效视频编码）

<span class="kg-badge kg-badge-codecs">编码</span>
<span class="kg-badge kg-badge-codec">高效</span>
<span class="kg-badge kg-badge-ai">4K</span>

**H.265/HEVC** = High Efficiency Video Coding，H.264 的继任者，压缩率提升 50%。

## 📊 基本信息

| 项 | 值 |
| --- | --- |
| 推出 | 2013 |
| 标准号 | ITU-T H.265 / ISO/IEC 23008-2 |
| 制定方 | ITU-T VCEG + ISO/IEC MPEG (JCT-VC) |
| 现状 | 4K/HDR 主流 |
| 压缩率 | 较 H.264 节省 40-50% |
| 复杂度 | 编码 +200%，解码 +50% |
| 专利 | 需付费（多个专利池，HEVC Advance / MPEG LA） |

## 🏗️ 相比 H.264 的改进

| 改进 | 说明 |
| --- | --- |
| **块尺寸** | CTU 最大 64×64 |
| **四叉树划分** | 灵活块大小 |
| **预测模式** | 35 种帧内模式 |
| **MV 精度** | 1/8 像素 |
| **变换尺寸** | 4×4 ~ 32×32 |
| **变换类型** | DCT-VIII / DST-VII |
| **熵编码** | CABAC |
| **环路滤波** | DF + SAO |
| **并行工具** | WPP, Tiles |

## 📐 块结构

```
CTU (64×64)
  ├─ CU (Coding Unit, 4×4 ~ 64×64)
  │   ├─ PU (Prediction Unit)
  │   └─ TU (Transform Unit, 4×4 ~ 32×32)
  └─ 四叉树递归划分
```

### 划分模式

```
CTU 64×64
├─ CU 64×64
├─ CU 32×32 ├─ CU 32×32 ├─ CU 16×16 ├─ CU 8×8
│           │           │           └─ ...
│           │           └─ CU 16×16
│           └─ CU 32×32
└─ CU 64×64
```

## 🎯 帧内预测

| 模式 | 数量 |
| --- | --- |
| DC | 1 |
| Planar | 1 |
| 角度 | 33 (3-34) |
| **合计** | **35** |

### 角度模式

```
模式 26 = 垂直（参考左边）
模式 10 = 水平（参考上边）
模式 2  = DC
模式 0  = Planar
其他 33 个角度 ±32
```

## 🎯 帧间预测

| 特性 | H.265 vs H.264 |
| --- | --- |
| 块大小 | 最大 64×64 vs 16×16 |
| 块形状 | 不对称支持 |
| 1/8 像素 | 支持（vs 1/4） |
| AMVP | 高级 MV 预测 |
| Merge/Skip | 统一 |
| BIO | 双向光流补偿 |

## 📊 NAL Unit

```
H.265 NAL Unit:
  Header 2 byte:
    F (1 bit)
    Type (6 bit):
      0-9: VCL
      16-21: 非 VCL
        32: VPS
        33: SPS
        34: PPS
        39: SEI
    LayerId (6 bit)
    TID (3 bit) = TemporalId
```

### HEVC 码流结构

```
VPS (Video Parameter Set)
SPS (Sequence Parameter Set)
PPS (Picture Parameter Set)
SEI (Optional)
IDR Slice (RASL / RADL / IDR_W_RADL / IDR_N_LP)
Non-IDR Slice
...
```

## 🎯 SAO

H.265 新增，分 Band / Edge 两类补偿。

```
Band: 32 个 band，按像素值范围偏移
Edge: 4 个方向（0/90/135/45°）
```

## 🛠️ FFmpeg 编码

```bash
# H.265 编码
ffmpeg -i input.mp4 -c:v libx265 -crf 28 -preset medium -tag:v hvc1 output.mp4

# 10bit HDR
ffmpeg -i input.mp4 -c:v libx265 -pix_fmt yuv420p10le -tag:v hvc1 output.mp4

# 4:2:2 / 4:4:4
ffmpeg -i input.mp4 -c:v libx265 -pix_fmt yuv422p -tag:v hvc1 output.mp4

# 调参
-x265-params "keyint=250:bframes=4:ref=3:rd=4"
```

## ⚠️ 专利困境

```
H.265 专利分散:
  - MPEG LA（~50 家公司）
  - HEVC Advance（~30 家公司）
  - 单独专利（Technicolor 等）

→ 多个专利池，授权复杂
→ 推动 AV1 发展（免专利）
```
