# H.264 / AVC（高级视频编码）

<span class="kg-badge kg-badge-codecs">编码</span>
<span class="kg-badge kg-badge-codec">主流</span>
<span class="kg-badge kg-badge-protocol">流媒体</span>

**H.264/AVC** = Advanced Video Coding，国际标准 ISO/IEC 14496-10 / ITU-T H.264。

## 📊 基本信息

| 项 | 值 |
| --- | --- |
| 推出 | 2003 |
| 标准号 | ITU-T H.264 / ISO/IEC 14496-10 / MPEG-4 Part 10 |
| 制定方 | ITU-T VCEG + ISO/IEC MPEG (JVT) |
| 现状 | **事实标准**，最广泛使用 |
| 压缩率 | 基准（MPEG-2 的 ~50%） |
| 复杂度 | 中 |
| 专利 | 需付费（MPEG LA 专利池） |

## 🏗️ 编码特性

| 特性 | 说明 |
| --- | --- |
| **块尺寸** | 4×4 ~ 16×16 |
| **预测模式** | I/P/B/SI/SP |
| **变换** | 4×4 整数 DCT, 8×8 整数 DCT |
| **熵编码** | CAVLC / CABAC |
| **去块** | 必有 |
| **环路滤波** | 仅去块 |
| **多参考** | 最多 16 |
| **加权预测** | 支持 |

## 📐 Profile 与 Level

### Profile

| Profile | 特点 | 用途 |
| --- | --- | --- |
| **Baseline** | 无 B 帧，无 CABAC，无 interlacing | 视频会议、低端 |
| **Constrained Baseline** | Baseline 子集 | Apple FaceTime |
| **Main** | B 帧 + CABAC | 标清电视 |
| **Extended** | Main + SI/SP | 流媒体 |
| **High** | Main + 8×8 DCT + 高精度 ME | 蓝光、HDTV |
| **High 10** | High + 10bit | 专业广播 |
| **High 4:2:2** | High + 4:2:2 | 专业 |
| **High 4:4:4 Predictive** | High + 4:4:4 | 专业 |
| **CAVLC 4:4:4 Intra** | 仅 I 帧 | 专业 |

### Level

| Level | 最大码率 | 分辨率@帧率 |
| --- | --- | --- |
| 1.0 | 64 Kbps | 176×144@15 |
| 1.3 | 768 Kbps | 320×240@30 |
| 2.0 | 2 Mbps | 352×480@30 |
| 3.0 | 10 Mbps | 720×480@30 |
| 3.1 | 14 Mbps | 1280×720@30 |
| 4.0 | 20 Mbps | 1920×1080@30 |
| 4.1 | 50 Mbps | 1920×1080@30 |
| 5.0 | 135 Mbps | 1920×1080@72 |
| 5.1 | 240 Mbps | 4096×2304@30 |

## 🎯 关键算法

### 帧内预测

| 块大小 | 模式数 |
| --- | --- |
| 4×4 | 9 |
| 8×8 | 9 |
| 16×16 | 4 |

### 帧间预测

| 块划分 | 16×16, 16×8, 8×16, 8×8, 8×4, 4×8, 4×4 |
| 亚像素 | 1/2 (6-tap), 1/4 (双线性) |

## 📊 NAL Unit（网络抽象层）

```
H.264 码流 = NAL Unit 序列

NAL Header 1 byte:
  F (1 bit)  = forbidden_zero_bit
  NRI (2 bit) = nal_ref_idc
  Type (5 bit) = nal_unit_type

Type:
  1: 非 IDR 切片
  5: IDR 切片
  6: SEI
  7: SPS
  8: PPS
  9: AU 分隔符
```

### 码流结构

```
H.264 Stream:
  SPS (Sequence Parameter Set)
  PPS (Picture Parameter Set)
  IDR Slice
  Non-IDR Slice
  Non-IDR Slice
  ...
  SEI
  SPS
  PPS
  IDR Slice
  ...
```

## 📦 Annex B vs AVCC

| 格式 | 起始码 | 用途 |
| --- | --- | --- |
| **Annex B** | 0x000001 / 0x00000001 | 传统 .h264 文件、流 |
| **AVCC** | 长度前缀 (4 byte) | MP4 容器 |
| **HVCC** | 长度前缀 | HEVC |

## 🛠️ FFmpeg 编码

```bash
# 默认 H.264 编码
ffmpeg -i input.mp4 -c:v libx264 -crf 23 -preset medium output.mp4

# High Profile
ffmpeg -i input.mp4 -c:v libx264 -profile:v high -level 4.1 output.mp4

# Baseline (兼容老设备)
ffmpeg -i input.mp4 -c:v libx264 -profile:v baseline output.mp4

# 无损 H.264
ffmpeg -i input.mp4 -c:v libx264 -crf 0 -preset ultrafast output.mp4

# 关键参数
-preset ultrafast|fast|medium|slow|veryslow
-tune film|animation|grain|stillimage|fastdecode|zerolatency
-x264-params "keyint=250:min-keyint=25:bframes=3:ref=3"
```

## 📌 应用场景

| 场景 | 原因 |
| --- | --- |
| **视频会议** | Baseline 兼容、低延迟 |
| **蓝光光盘** | High Profile |
| **直播推流** | 兼容性 + 实时 |
| **监控录像** | Baseline + 低成本 |
| **微信视频** | Baseline 兼容 |
| **iPhone 录制** | High Profile 高效 |
