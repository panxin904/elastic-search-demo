# 视频本质 - 像素与帧

<span class="kg-badge kg-badge-basics">基础</span>
<span class="kg-badge kg-badge-codecs">入门</span>

视频 = 一组**按时间顺序**连续播放的**静态图像**（帧），通过人眼的**视觉暂留**现象产生连续运动的感觉。

## 🎬 视频三要素

| 要素 | 含义 | 典型值 |
| --- | --- | --- |
| **像素（Pixel）** | 图像的最小单位，每个像素携带颜色信息 | RGB / YUV |
| **帧（Frame）** | 一张静态画面，多帧组成视频 | 24fps / 30fps / 60fps |
| **时间（Time）** | 帧与帧之间的时间间隔 | 1/24s ≈ 41.67ms |

## 📐 像素结构

每个像素由若干**色彩分量**组成，常见模型：

```
RGB 模型（显示）
  R (Red 红)  : 8/10/12 bit
  G (Green 绿): 8/10/12 bit
  B (Blue 蓝) : 8/10/12 bit

YUV 模型（编码）
  Y  (亮度 Luma)  : 8/10/12 bit
  Cb (蓝色差)     : 8/10 bit
  Cr (红色差)     : 8/10 bit
```

> **为什么视频用 YUV？** 人眼对亮度敏感、对色度不敏感，YUV 可以对色度**降采样**（4:2:0 / 4:2:2）节省带宽。

## 📊 一帧图像的数据量

```
未压缩 1 帧 1080p (1920×1080) YUV 4:2:0 (8bit):
  Y:   1920 × 1080 × 1 byte = 2,073,600 byte
  Cb:  960  × 540  × 1 byte =   518,400 byte
  Cr:  960  × 540  × 1 byte =   518,400 byte
  ──────────────────────────
  Total: 3,110,400 byte ≈ 3 MB

1 秒 30fps 视频 ≈ 90 MB
1 分钟 ≈ 5.4 GB

→ 这就是为什么视频必须压缩（编码）。
```

## 🎞️ 帧类型

| 类型 | 说明 | 压缩率 |
| --- | --- | --- |
| **I 帧** (Intra) | 关键帧，独立编码，不依赖其他帧 | 最低 |
| **P 帧** (Predicted) | 前向参考帧，只编码与前一帧的差异 | 中 |
| **B 帧** (Bi-predictive) | 双向参考帧，可参考前后帧 | 最高 |
| **IDR 帧** | 即时解码刷新，H.264 特殊 I 帧 | 最低 |

## 🎥 帧序列示例

```
帧序列: I P B B P B B P B B I P B B P B B ...
        │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │ │
        └─┴─┴─┴─┴─┴─┴─┴─┴─┴─┘   └─┴─┴─┴─┴─┴─┘
         ←── GOP 1 ────→         ←── GOP 2 ──→
        (Group of Pictures)
```

## 🧠 人眼视觉特性

| 特性 | 应用 |
| --- | --- |
| 视觉暂留 (约 100ms) | 帧率 ≥ 10fps 才有连续感 |
| 对亮度敏感 / 色度弱 | YUV 4:2:0 降采样 |
| 对高频不敏感 | DCT 量化丢弃高频 |
| 整体感知 / 局部忽略 | 帧间预测、ROI 编码 |

## 📈 关键参数速记

| 参数 | 含义 | 常用范围 |
| --- | --- | --- |
| 分辨率 | 像素数量 | 720p / 1080p / 2K / 4K / 8K |
| 帧率 fps | 每秒帧数 | 24 / 25 / 30 / 50 / 60 / 120 |
| 码率 bps | 每秒比特数 | 500K ~ 50M |
| 采样率 | 音频每秒采样 | 44.1K / 48K Hz |
| 位深 bit | 每分量比特数 | 8 / 10 / 12 bit |
| 色域 | 颜色范围 | Rec.709 / Rec.2020 |
| HDR | 高动态范围 | HDR10 / HLG / Dolby Vision |
