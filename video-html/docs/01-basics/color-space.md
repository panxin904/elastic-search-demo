# 色彩空间 - YUV / RGB

<span class="kg-badge kg-badge-basics">基础</span>
<span class="kg-badge kg-badge-algorithm">色彩</span>

视频系统中存在多种色彩模型，目的都是**用最少的数据描述人眼可感知的颜色**。

## 🎨 RGB 模型

```
R(Red 红) + G(Green 绿) + B(Blue 蓝) → 任何颜色
```

| 颜色 | R | G | B |
| --- | --- | --- | --- |
| 黑 | 0 | 0 | 0 |
| 白 | 255 | 255 | 255 |
| 红 | 255 | 0 | 0 |
| 绿 | 0 | 255 | 0 |
| 蓝 | 0 | 0 | 255 |
| 黄 | 255 | 255 | 0 |

**用途**：显示器、相机传感器、图像文件（BMP/PNG）

## 📺 YUV 模型（亮度 + 色度）

```
Y = 亮度 Luma（黑白灰阶）
U = 蓝色差 Cb = B - Y
V = 红色差 Cr = R - Y
```

### BT.601 / BT.709 / BT.2020

| 标准 | Y 范围 | U/V 范围 | 使用场景 |
| --- | --- | --- | --- |
| **BT.601** | 16-235 | 16-240 | 标清 SD（576i / 480i） |
| **BT.709** | 16-235 | 16-240 | **高清 HD**（720p / 1080p） |
| **BT.2020** | 16-235 | 16-240 | **4K / 8K** 超高清 |
| **BT.2100** | 16-235 | 16-240 | **HDR** |

## 🗜️ YUV 色度降采样

**关键**：人眼对色度不敏感，可以**降采样**色度节省带宽。

| 采样格式 | 每 4 像素 | Y 大小 | Cb 大小 | Cr 大小 | 压缩率 |
| --- | --- | --- | --- | --- | --- |
| **YUV 4:4:4** | 4Y + 4Cb + 4Cr | 4 | 4 | 4 | 无损 |
| **YUV 4:2:2** | 4Y + 2Cb + 2Cr | 4 | 2 | 2 | 50% |
| **YUV 4:2:0** | 4Y + 1Cb + 1Cr | 4 | 1 | 1 | 50% |
| **YUV 4:1:1** | 4Y + 1Cb + 1Cr | 4 | 1 | 1 | 50% |

> 📌 **H.264 / H.265 默认 4:2:0**，专业广播（ProRes）使用 4:2:2。

### 4:2:0 存储布局

```
┌─────────┬─────────┐
│  Y0     │  Y1     │
│ (Cb0Cr0)│ (Cb1Cr1)│
├─────────┼─────────┤
│  Y2     │  Y3     │
│ (Cb0Cr0)│ (Cb1Cr1)│
└─────────┴─────────┘
```

## 🔁 RGB ↔ YUV 转换公式

### BT.601 数字域

```
Y =  0.257·R + 0.504·G + 0.098·B + 16
Cb = -0.148·R - 0.291·G + 0.439·B + 128
Cr =  0.439·R - 0.368·G - 0.071·B + 128
```

### BT.709 数字域（高清）

```
Y =  0.213·R + 0.715·G + 0.072·B + 16
Cb = -0.117·R - 0.394·G + 0.511·B + 128
Cr =  0.511·R - 0.464·G - 0.047·B + 128
```

## 🎬 其他色彩模型

| 模型 | 用途 |

| **HSV / HSL** | 图像处理（Photoshop） |

## 📊 色域（Color Gamut）

| 色域 | 范围 | 用途 |
| --- | --- | --- |
| **sRGB** | BT.709 + gamma 2.2 | 互联网 / 显示器 |
| **Display P3** | DCI-P3 | Apple 设备 |
| **Rec.709** | 高清电视 | 直播 / 蓝光 |
| **Rec.2020** | 超高清 | 4K / 8K |
| **DCI-P3** | 数字影院 | 电影院 |
| **Rec.2020 + ST.2084** | HDR | HDR10 / Dolby Vision |

## 🎯 HDR（高动态范围）

| 标准 | 元数据 | 色域 | 峰值亮度 |
| --- | --- | --- | --- |
| **HDR10** | 静态 | Rec.2020 | 1000 / 4000 nit |
| **HDR10+** | 动态 | Rec.2020 | 4000 nit |
| **Dolby Vision** | 动态 | Rec.2020 | 10000 nit |
| **HLG** | 无 | Rec.2020 | 自适应 |

## 🛠️ FFmpeg 实操

```bash
# 查看像素格式
ffprobe -show_streams -select_streams v:0 input.mp4 | grep pix_fmt

# RGB → YUV
ffmpeg -i input.png -pix_fmt yuv420p output.yuv

# YUV420 → RGB24
ffmpeg -pix_fmt yuv420p -s 1920x1080 -i input.yuv -pix_fmt rgb24 output.png

# BT.709 ↔ BT.601 转换
ffmpeg -colorspace bt709 -i hd.mp4 -colorspace bt601 sd.mp4
```

## 📌 面试考点

1. 为什么视频编码用 YUV 而不是 RGB？
   - 人眼对色度不敏感，YUV 4:2:0 节省 50% 带宽
2. 4:2:0 和 4:4:4 的区别？
   - 色度降采样率不同
3. BT.601 / 709 / 2020 区别？
   - 不同分辨率和色域标准
4. sRGB 和 Display P3 的差异？
   - 色域范围不同，P3 更广
