# Java 学习路径
- Junior (1-2yr): Core Java, Collections, basic concurrency, Spring Boot CRUD, SQL
- Mid (3-5yr): JVM tuning, JUC, microservices (Spring Cloud), design patterns, testing
- Senior (5-8yr): JVM internals, GC tuning, distributed systems, performance optimization
- Architect (8-12yr): System design, CAP theorem, event-driven, domain-driven design
- Principal (12+yr): Technical strategy, mentoring, open source contributions
