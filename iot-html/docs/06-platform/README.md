| 节点 | 一句话 |
|------|--------|

## 选型决策

- 公有云（运维省心 / 成本可控）：阿里云 / AWS
- 自建（数据自主 / 长期省钱）：EMQX + ThingsBoard
- 智能家居：Matter（跨生态）
- 工业场景：OPC-UA + IIoT 平台
