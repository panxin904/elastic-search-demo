# BM25 相关度算法

## 📌 一句话定义
BM25 (Best Matching 25) 是 ES 7.x 默认的**文档评分算法**，用于衡量 query 与 document 的相关度。

## 📐 BM25 公式

```
score(D, Q) = Σ IDF(qi) · (f(qi, D) · (k1 + 1)) / (f(qi, D) + k1 · (1 - b + b · |D| / avgdl))
```

| 符号 | 含义 |
|---|---|
| `f(qi, D)` | 词 qi 在文档 D 中的词频 |
| `|D|` | 文档 D 的长度（词数） |
| `avgdl` | 所有文档平均长度 |
| `k1` | 词频饱和参数（默认 1.2） |
| `b` | 文档长度归一化参数（默认 0.75） |
| `IDF(qi)` | 逆文档频率（罕见词权重高） |

## 🎯 参数调节

```http
PUT /products
{
  "settings": {
    "similarity": {
      "my_bm25": {
        "type": "BM25",
        "k1": 1.5,        // 词频影响更大
        "b":  0.5         // 文档长度影响降低
      }
    }
  },
  "mappings": {
    "properties": {
      "name": {
        "type": "text",
        "similarity": "my_bm25"
      }
    }
  }
}
```

| 参数 | 调大效果 |
|---|---|
| `k1` | 词频对评分影响更大（长文档多次出现更重要） |
| `b` | 文档长度归一化更强（短文档优势降低） |

## 📊 与 TF-IDF 的对比

| 维度 | TF-IDF | BM25 |
|---|---|---|
| 词频饱和 | 线性增长 | **有上限**（k1 控制） |
| 文档长度 | 不归一化 | **归一化**（b 控制） |
| IDF 公式 | log(N/df) | log((N-df+0.5)/(df+0.5)+1) |
| 实用性 | 经典 | **现代主流** |

## 🎯 评分影响因素

| 因素 | 方向 |
|---|---|
| 词频 TF | 越多越高（有上限） |
| 逆文档频率 IDF | 罕见词越高 |
| 文档长度 | 短文档天然优势 |
| 字段长度归一化 | 短字段命中更重要 |
