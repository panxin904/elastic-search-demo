# 知识图谱

按章节组织的 76 个核心节点关系图。点击节点跳转对应文档。

## 图例说明

13 种颜色对应 13 个章节，节点大小表示该知识点的重要性/复杂度。边表示节点间的依赖或衍生关系（如「日志」概念应用于 ext4 / XFS / NTFS 等多个本地盘 FS）。

## 使用技巧

- 鼠标拖拽节点重新布局
- 滚轮缩放
- 点击节点跳转文档
- hover 显示节点信息
- "重置布局"按钮恢复初始状态
- 节点按章节着色，可直观看出某个章节涉及哪些核心概念
