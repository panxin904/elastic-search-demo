## 阅读建议

每个案例包含：
- **背景**：业务规模与挑战
- **架构**：核心组件与数据流
- **演进**：从 v1 到 vN 的关键决策
- **教训**：踩过的坑与最佳实践

这些案例不是"标准答案"，而是"特定约束下的最优解"——理解背后的**约束**比抄架构更重要。
