关于 Scholar's Atlas

📚 这是什么

Scholar's Atlas 是一个面向后端工程师、前端工程师、AI 工程师、SRE 的系统性技术知识门户，包含 26 个 VitePress 子站点，统一部署在 https://java-px.bot.cd。

🎯 适合谁

  • 求职准备（C++/Java/Go/Python 后端、面试高频八股）
  • 在职充电（系统化补齐短板，对标高级 / 架构师）
  • 团队培训（新成员 onboarding、技术分享素材）

🔧 怎么搭的

  • 静态站生成：VitePress 1.6 + Markdown
  • 服务器：Ubuntu 22.04 + nginx 1.18（HTTP/2 + Let's Encrypt）
  • 部署：本地 build-release.sh → deploy-fs.sh 原子发布（/var/www/sites-hub/releases/<ts> → current symlink）
  • 认证：Basic Auth（htpasswd -b -i）

📐 内容规范

  • 每个主题分 4 个入口：首页（VPHero 概览）+ 知识图谱（graph.html）+ 思维导图（mindmap.html）+ 命令速查（cheatsheet.html）+ 学习路径（path.html）
  • 章节按数字前缀排序（01-xxx/、02-xxx/ ...），方便查阅时定位
  • 所有站点头部导航第一个都是 🏠 门户（回到本页面）
