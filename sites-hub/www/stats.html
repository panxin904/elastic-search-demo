📊 访问统计

本页基于 GoAccess 实时分析 nginx 访问日志生成。

首次部署说明：VPS 首次部署后需要运行一次 setup-goaccess.sh（详见 §8.37），之后每日 0:00 cron 自动重新生成。

📈 数据维度

  • 每日 PV / UV / 独立 IP
  • Top 页面（哪些文档最常被访问）
  • 来源（referer / 直接访问 / 搜索）
  • HTTP 状态码分布（4xx / 5xx）
  • 客户端类型（浏览器 / 爬虫）

🔧 资源占用

  • GoAccess 二进制：~5MB
  • 运行 RAM：~30MB（每次 ~30s）
  • 持久化 DB：~5MB（30 天）
  • 输出 HTML：~300KB

对比 Plausible SaaS：0 外部依赖，0 cookie，0 GDPR 顾虑，完全本地分析。
